# legacy/ — 第一版參考素材（不是規格）

這裡放的是 **v0.1.x 第一版** 的程式、文件、測試與試玩表單。

## 規則（接手開發必讀）

1. **唯一規格是 [`docs/規格書.md`](../docs/規格書.md)**。本目錄任何內容與規格書衝突時，以規格書為準。
2. **不要在 `legacy/` 上繼續改出新功能。** 第二版程式從最小雛形重寫（見規格書「技術」「第一個雛形」）。
3. 這裡只供查閱：開場四幕台詞、人物說話方式、美術檔名對照、舊測試寫法、舊決策脈絡。
4. 第一版的 D 編號決策、Q 編號問題 **全部失效**（規格書已定案）。

## 目錄說明

| 路徑 | 內容 | 規格書怎麼說 |
| --- | --- | --- |
| `src/` | 第一版全部程式 | 搬來只當參考，不在上面改 |
| `index.html`、`manifest.webmanifest` | 第一版入口與 PWA | 同上 |
| `docs/第一站劇本.md` | 開場四幕台詞、熟客里程碑原稿 | 開場四幕含台詞沿用；其餘重寫 |
| `docs/人物誌.md` 的姊妹文件 | 企劃、提案、美術清單、開發計畫、待定審稿 | 人物設定以根目錄 `docs/人物誌.md` 為準；其餘只供參考 |
| `tests/` | 第一版單元／冒煙／通關／pending | 測試**框架**沿用（根目錄 `package.json`、`tests/serve.mjs`）；這些舊測例不維護 |
| `.github/ISSUE_TEMPLATE/playtest.yml` | 第一版試玩表單 | 失效 |

## 規格書明確沿用、但素材在這裡的東西

- 開場四幕台詞：`src/opening.js`、`src/letters.js`，以及 `docs/第一站劇本.md`
- 熟客／德叔說話方式參考：`src/story.js`、`src/farewell.js`、`src/afterhours.js` 等（寫新台詞時對 `docs/人物誌.md` + 避免 AI 味檢核表）
- 舊測試寫法範例：`tests/unit/`、`tests/smoke.mjs`

畫師美術仍在根目錄 `assets/art/`（規格書：沿用），Three.js vendor 仍在根目錄 `vendor/`。
