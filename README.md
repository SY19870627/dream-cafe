# 我單方面辭退老闆後，開了一間夢想中的咖啡店

一款給台灣小資族的療癒放置遊戲：不用真的掏出開店資金，下班後也能回到一間屬於自己的咖啡店。

這個 repo 目前是 **試玩版**（第一版：台南東山一站，從開場玩到第一站結尾），線上試玩：https://sy19870627.github.io/dream-cafe/ 。開發進度見 [docs/第一版開發計畫.md](docs/第一版開發計畫.md)。

## 試玩說明

給來試玩的朋友：

- **用手機打開** https://sy19870627.github.io/dream-cafe/ ，直立拿著玩（電腦也可以，畫面會是一條直的）。不用安裝、不用註冊，免費。
- **怎麼玩**：第一次打開會先看到 16:49 的辦公室，寫完辭呈之後一路走到東山的店。進店以後，點座位坐下、請德叔沖一杯、看他慢慢沖；「佈置」可以用溫度基金買擺飾、擺放永遠免費。牆上的溫度計會慢慢從 20°C 爬到 37°C，不用刻意追。
- **一天打開一下就好**：遊戲時間跟現實一樣，一天就是一天。你不在的日子，德叔會寫營業日誌給你；熟客重要的事會等你在店裡才發生。每天花幾分鐘坐一下、按「打烊」喝最後一杯，大約三週會走到第一站的結尾。沒有每日簽到，幾天沒來也不會少什麼。
- **聲音**：點過畫面之後會有很小聲的音樂和店裡的聲音（磨豆、注水、門鈴、雨）；右上角「≡」可以分別關掉音樂、店裡的聲音，或把音量調大。
- **存檔**：存在這台手機的瀏覽器裡（不會上傳）。換手機、清除瀏覽資料或用私密瀏覽，進度不會留下。
- **回饋**：右上角「≡」→「留下試玩心得」（GitHub 的試玩表單，每一題都可以不填）；沒有 GitHub 帳號的話，直接傳訊息給開發者也可以。遊戲本身不收集任何資料。
- **特別想知道**：下班後打開它，有沒有放鬆一點？哪裡讓你覺得像在上班、被催、或不知道該做什麼？畫面順不順、手機會不會發燙？會不會想「回店裡看看」？

## 原型內容

- 開場四幕：16:49 的辦公室寫完辭呈（三選一結尾、可以署名）→ 信箱裡的律師信 → 傍晚的 175 縣道 → 推門進店，德叔沖第一杯、送三件初始擺飾；只在第一次玩時出現，每一幕都可以略過
- 德叔的營業日誌：隔天以後回到店裡，德叔用手寫的日誌回報老闆不在的日子（每天 2～4 條：來了幾位客人、龍眼換到哪裡睡、下雨了沒……），離開很多天時只展開最近 3 天
- 第一封老先生的信：開店第 2 天或溫度到 22°C，德叔從吧台抽屜拿出來；讀完可以在記事本重讀
- 台南東山的第一間店：三合院紅磚牆、窗外的山與龍眼樹
- 三個座位：窗邊座、吧台座、角落沙發，點一下就能坐下，用客人的角度看店
- 坐下後左右拖曳可以環顧四周
- 咖啡管家德叔：按下沖咖啡後鏡頭會移到吧台特寫，看他溫杯、磨豆、悶蒸、注水、倒進杯子，再走過來端上桌（吧台沖煮約 20 秒）；沖煮中可以在「回座位」與「看德叔沖」之間切換，按住畫面德叔的動作會快一點
- 對話泡泡只用在角色說話，點德叔、熟客可以搭話，點龍眼可以摸他（點太多次他會走開，一陣子不理人）
- 三位熟客的故事線（各 6 個里程碑）：作家予安總坐窗邊、返鄉青農阿哲不定時拎東西來、遠距工程師凱文每天下午五點來點冰美式。老闆不在時可以發生的事寫進德叔的日誌；重要的時刻（予安說出龍眼窯、颱風夜、凱文問你怎麼敢辭職……）等老闆在店裡才發生，需要回答時畫面下方出現選項。熟客會送東西（寫滿字的紙巾、予安的書），菜單會多出窯烤龍眼乾與「阿哲的豆」
- 店裡的天氣：依季節的雨天（窗外下雨、雨打在鐵皮雨遮上）與第 2 週的颱風夜（風、悶雷）；冬天雨少，還沒在雨天坐過窗邊的話，第 12 天起每隔幾天會保底下一場雨
- 聲音與音樂（全部用瀏覽器即時合成，沒有音檔）：慵懶的電鋼琴背景音樂（打烊後換成更慢的夜曲，擺了黑膠唱機會有唱針聲）、磨豆、熱水壺注水、杯子放上桌、推門的門鈴、關燈的「喀」、窗外經過的機車、雨聲；開場的辦公室只有日光燈的嗡嗡聲和鍵盤聲。音量預設很小，選單可以分別關掉
- 店貓龍眼：睡覺的地方跟著擺飾換（有書櫃就睡書架上、有軟墊就睡軟墊……），德叔的日誌會寫他換到哪裡；老闆坐一會兒再站起來，他會跳上那張還熱著的椅子；也會陪熟客
- 打烊後模式：俯瞰時按「打烊」，客人離開、德叔去門口翻牌子、天色暗下來；坐下後德叔沖「最後一杯，是老闆的」。打烊後每盞燈旁邊有「關燈」，一盞一盞自己關；可以整理擺飾、摸龍眼、寫一句「今天的一杯」咖啡日記，德叔在吧台擦他的琺瑯杯。沒有任何提示。按「明天見」畫面暗下來；同一天重新整理，店還是打烊後的樣子。予安念稿也在打烊後發生
- 一次客人模式：溫度到 28°C 之後，德叔會問「老闆，今天要不要從門口進來一次？」——推門進店、「歡迎。不急，先坐。」、德叔過來點單，坐著聽兩位熟客聊這間店（依店裡擺了什麼說不同的話）
- 第一站的結尾：溫度到 37°C 後，徵店長與告別在老闆在場時依序發生，可以分幾天看完——打烊後德叔看著溫度計說「這間店已經會自己呼吸了」、老闆從三張徵才啟事選一張貼在門口；隔天凱文穿著燙過的襯衫來面試、予安送上裱框的紙巾；再隔天阿哲送一包「阿哲的豆」、說起花蓮舞鶴那棵很老的咖啡樹，德叔把吧台的鑰匙交給凱文；那天打烊後，德叔用那個琺瑯杯沖了最後一杯，第一次叫了老闆的名字。隔天早上德叔拿出第二封老先生的信，讀完出發，畫面打開「你的咖啡地圖」（只亮東山一盞燈，下一站待續）
- 之後的東山：店轉為常態經營，凱文在吧台後面顧店（沖咖啡、打烊、營業日誌都由他接手），老闆隨時可以從門口推門進來坐坐；咖啡地圖可以從記事本重看
- 存檔：進度存在瀏覽器的 localStorage（`dream-cafe.save`），重新整理或隔天再來都還在；私密瀏覽存不了檔時照常遊戲
- 遊戲時間：現實一天＝遊戲一天，標題列顯示「開店第 N 天」
- 牆上的老溫度計與劇本的 20 個溫度任務（20°C → 37°C）；完成時溫度慢慢爬升、溫度基金撥款，由德叔一句話帶出，不跳任務清單。20 個任務都玩得到
- 佈置：倉庫裡有德叔送的三件擺飾；「德叔的型錄」有 16 件擺飾與家具，試擺不花錢，按「確定」才用溫度基金買下，「復原」回到進來時的樣子；擺放與移動永遠免費。靠牆的東西會自動貼牆，不會擋到窗戶與溫度計
- 白天 5200K／夜晚 2700K 色溫切換：下班後（18:00 到清晨 6 點）進店自動是夜裡的光線，也可以自己切（落地燈晚上會亮；打烊後由老闆自己關燈）
- 右上角「≡」：店的記事本（已經發生的事、最近一頁營業日誌、律師信與讀過的信、予安的稿子與扉頁、「今天的一杯」咖啡日記、店裡的熟客、菜單）、音樂／音量／店裡的聲音、關於這款遊戲、開發者資訊與「留下試玩心得」

## 技術做法

- [Three.js](https://threejs.org/) 0.187，打包成單一檔案放在 `vendor/`，不需要建置步驟
- 房間、吧台、桌子是簡單的 3D 幾何；人物與小擺飾是永遠面向鏡頭的 2D 紙片（billboard）
- 所有美術目前都在 `src/art.js` 用 Canvas 程式繪製，之後換成手繪插畫時，只要讓同名函式回傳圖片即可
- 音樂與音效都在 `src/audio.js` 用 WebAudio 即時合成，之後換成正式音樂或音檔只要改這裡
- 效能：解析度最高 2 倍，手機畫不到 40 FPS 時自動降低解析度；開場的全螢幕畫面期間不畫 3D 場景

## 本機執行

ES module 需要透過 HTTP 開啟，任選一種：

```bash
npm run serve            # Node 內建伺服器，http://127.0.0.1:8000
python3 -m http.server 8000
```

GitHub Pages 直接從 main 分支根目錄發佈（根目錄有 `.nojekyll`），push 後約一兩分鐘上線。

## 開發者模式

網址加 `?dev=1`：右上角出現「快轉」鈕；`?dev=1&speed=20` 可以直接指定動作倍率；`&opening=0` 直接當作看過開場；`&regulars=0` 關掉熟客；`&weather=rain`（或 `typhoon`、`clear`）指定店裡的天氣；`&guest=1` 不看溫度，店裡安靜下來就邀請老闆當一次客人；`&night=1` 一進店就是夜裡（開發者模式不看時鐘，預設白天）。「≡」選單裡多了開發者工具：跳到明天、跳 7 天（等於老闆離開那幾天，德叔會交出營業日誌，熟客這幾天的事也一起結算）、基金 +5,000、重置存檔（跳過的天數存在存檔裡，一般網址不採用），上方那行字顯示三位熟客與告別的進度，下一行是 FPS、解析度倍率、每幀繪製次數與貼圖張數；「告別前（36.5°C）」直接走完三條熟客線、溫度到 36.5°C（只留「擺上第一件擺飾」），擺一件東西就是 37°C，接著按「打烊」就會開始告別。想一口氣看完三條熟客線：坐下後每次「跳到明天」，等當天的事演完再跳，大約跳到第 20 天（予安想等打烊的那天，站起來按「打烊」）。開發者模式另外提供 `window.__cafe` 給測試讀狀態，一般網址不會出現。

## 測試

```bash
npm install
npx playwright install chromium   # 第一次需要
npm test
```

`npm test` 先用 `node --test` 跑 `tests/unit/` 的純邏輯單元測試（存檔、開店天數、溫度任務、型錄結帳、營業日誌、交信條件、天氣、熟客里程碑、龍眼、打烊與咖啡日記、客人模式的對話、告別的段落與第二封信；`npm run test:unit` 可以單獨跑），再執行 `tests/smoke.mjs`：用 Chromium 在 390×844 與 1280×720 載入遊戲，檢查沒有 JS 錯誤、座位標籤完整、可點目標 ≥ 44px、沖一杯咖啡後杯子上桌看得見、溫度 20.0 → 20.5°C、佈置與型錄（試擺、復原、確定才扣錢）、重新整理後進度都在、跳天數完成「開店滿 3／7 天」、記事本、存不了檔時照常遊戲、關於面板的連結，以及開場四幕（略過、中途重新整理）、營業日誌、第一封信只交一次、舊存檔直接進店，以及一天一天跳天數走完三位熟客的 18 個里程碑（颱風夜、凱文的三選一、選豆子、記事本）與雨天坐窗邊，以及龍眼（跳上椅子、拒絕互動、換到新的軟墊睡）、打烊後（最後一杯、關燈、咖啡日記、明天見、重新整理、隔天重新開門）、一次客人模式，以及從 36.5°C 走完徵店長與告別的七段、第二封信、咖啡地圖、重新整理後仍是凱文顧店的常態店。聲音（點過畫面後出聲、沖咖啡的各段聲音、背景音樂、不爆音、選單的音樂／音量／店裡的聲音開關）、效能（解析度倍率、貼圖數）、試玩心得連結、常態店的按鈕。截圖存在 `tests/output/`（不進 git）。

另外兩個不放在 `npm test` 的工具：

```bash
npm run playthrough [輸出資料夾]   # 從新存檔像玩家一樣玩到第一站結尾（390×844 與 1280×720 各一次，沿路截圖，約半小時以上）
npm run pending                    # 從程式碼整理所有【待定】文本，產生 docs/待定文本審稿.md
```

`npm run playthrough` 不略過開場，自己買擺飾、坐遍座位、每天坐窗邊喝一杯再打烊，用開發者工具一天一天跳，直到 37°C 的告別、第二封信、咖啡地圖與回東山；每張截圖都檢查可點目標 ≥ 44px、按鈕沒有跑出畫面，最後檢查 20 個溫度任務、音樂與音效有出聲、沒有 JS 錯誤。只想跑一種尺寸：`SIZES=390x844 npm run playthrough`。
