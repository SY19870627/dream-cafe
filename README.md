# 我單方面辭退老闆後，開了一間夢想中的咖啡店

一款給台灣小資族的療癒放置遊戲：不用真的掏出開店資金，下班後也能回到一間屬於自己的咖啡店。

這個 repo 目前是 **2.5D 顧客視角原型**，用來驗證「2D 美術放進簡單 3D 房間」在手機直立畫面上的效果與流暢度。

## 原型內容

- 台南東山的第一間店：三合院紅磚牆、窗外的山與龍眼樹
- 三個座位：窗邊座、吧台座、角落沙發，點一下就能坐下，用客人的角度看店
- 坐下後左右拖曳可以環顧四周
- 咖啡管家德叔：溫杯 → 磨豆 → 悶蒸 → 注水 → 端上，每一步都慢慢來
- 店貓龍眼會自己換地方睡覺，熟客予安在角落寫稿
- 佈置模式：點擺飾，再點地板，就能移動盆栽、書櫃、黑膠唱機、落地燈、黑板立牌
- 白天 5200K／夜晚 2700K 色溫切換
- 牆上的老溫度計與兩個溫度任務
- 右上角的「快轉 ×4」只供測試用

## 技術做法

- [Three.js](https://threejs.org/) 0.187，打包成單一檔案放在 `vendor/`，不需要建置步驟
- 房間、吧台、桌子是簡單的 3D 幾何；人物與小擺飾是永遠面向鏡頭的 2D 紙片（billboard）
- 所有美術目前都在 `src/art.js` 用 Canvas 程式繪製，之後換成手繪插畫時，只要讓同名函式回傳圖片即可

## 本機執行

ES module 需要透過 HTTP 開啟：

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

也可以在 repo 設定開啟 GitHub Pages（Branch: main / root），用手機直接開。
