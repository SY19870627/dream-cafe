# 我單方面辭退老闆後，開了一間夢想中的咖啡店

一款給台灣小資族的療癒放置遊戲：不用真的掏出開店資金，下班後也能回到一間屬於自己的咖啡店。

這個 repo 目前是 **測試版**（2.5D 顧客視角原型往第一版推進中），線上試玩：https://sy19870627.github.io/dream-cafe/ 。開發進度見 [docs/第一版開發計畫.md](docs/第一版開發計畫.md)。

## 原型內容

- 開場四幕：16:49 的辦公室寫完辭呈（三選一結尾、可以署名）→ 信箱裡的律師信 → 傍晚的 175 縣道 → 推門進店，德叔沖第一杯、送三件初始擺飾；只在第一次玩時出現，每一幕都可以略過
- 德叔的營業日誌：隔天以後回到店裡，德叔用手寫的日誌回報老闆不在的日子（每天 2～4 條：來了幾位客人、龍眼換到哪裡睡、下雨了沒……），離開很多天時只展開最近 3 天
- 第一封老先生的信：開店第 2 天或溫度到 22°C，德叔從吧台抽屜拿出來；讀完可以在記事本重讀
- 台南東山的第一間店：三合院紅磚牆、窗外的山與龍眼樹
- 三個座位：窗邊座、吧台座、角落沙發，點一下就能坐下，用客人的角度看店
- 坐下後左右拖曳可以環顧四周
- 咖啡管家德叔：按下沖咖啡後鏡頭會移到吧台特寫，看他溫杯、磨豆、悶蒸、注水、倒進杯子，再走過來端上桌（吧台沖煮約 20 秒）；沖煮中可以在「回座位」與「看德叔沖」之間切換，按住畫面德叔的動作會快一點
- 對話泡泡只用在角色說話，點德叔、予安、龍眼可以搭話
- 店貓龍眼會自己換地方睡覺，熟客予安（卡稿的作家）在角落寫稿
- 存檔：進度存在瀏覽器的 localStorage（`dream-cafe.save`），重新整理或隔天再來都還在；私密瀏覽存不了檔時照常遊戲
- 遊戲時間：現實一天＝遊戲一天，標題列顯示「開店第 N 天」
- 牆上的老溫度計與劇本的 20 個溫度任務（20°C → 37°C）；完成時溫度慢慢爬升、溫度基金撥款，由德叔一句話帶出，不跳任務清單。目前玩得到的有：第一杯、擺上第一件擺飾、坐遍座位、開店滿 3／7 天、擺滿 10 件、第一面書牆；熟客、店貓與客人模式的任務會在之後的階段加入
- 佈置：倉庫裡有德叔送的三件擺飾；「德叔的型錄」有 16 件擺飾與家具，試擺不花錢，按「確定」才用溫度基金買下，「復原」回到進來時的樣子；擺放與移動永遠免費。靠牆的東西會自動貼牆，不會擋到窗戶與溫度計
- 白天 5200K／夜晚 2700K 色溫切換（落地燈晚上會亮）
- 右上角「≡」：店的記事本（已經發生的事、最近一頁營業日誌、律師信與讀過的信）、關於這款遊戲與開發者資訊

## 技術做法

- [Three.js](https://threejs.org/) 0.187，打包成單一檔案放在 `vendor/`，不需要建置步驟
- 房間、吧台、桌子是簡單的 3D 幾何；人物與小擺飾是永遠面向鏡頭的 2D 紙片（billboard）
- 所有美術目前都在 `src/art.js` 用 Canvas 程式繪製，之後換成手繪插畫時，只要讓同名函式回傳圖片即可

## 本機執行

ES module 需要透過 HTTP 開啟，任選一種：

```bash
npm run serve            # Node 內建伺服器，http://127.0.0.1:8000
python3 -m http.server 8000
```

GitHub Pages 直接從 main 分支根目錄發佈（根目錄有 `.nojekyll`），push 後約一兩分鐘上線。

## 開發者模式

網址加 `?dev=1`：右上角出現「快轉」鈕；`?dev=1&speed=20` 可以直接指定動作倍率；`&opening=0` 直接當作看過開場。「≡」選單裡多了開發者工具：跳到明天、跳 7 天（等於老闆離開那幾天，德叔會交出營業日誌）、基金 +5,000、重置存檔（跳過的天數存在存檔裡，一般網址不採用）。開發者模式另外提供 `window.__cafe` 給測試讀狀態，一般網址不會出現。

## 測試

```bash
npm install
npx playwright install chromium   # 第一次需要
npm test
```

`npm test` 先用 `node --test` 跑 `tests/unit/` 的純邏輯單元測試（存檔、開店天數、溫度任務、型錄結帳、營業日誌、交信條件、天氣；`npm run test:unit` 可以單獨跑），再執行 `tests/smoke.mjs`：用 Chromium 在 390×844 與 1280×720 載入遊戲，檢查沒有 JS 錯誤、座位標籤完整、可點目標 ≥ 44px、沖一杯咖啡後杯子上桌看得見、溫度 20.0 → 20.5°C、佈置與型錄（試擺、復原、確定才扣錢）、重新整理後進度都在、跳天數完成「開店滿 3／7 天」、記事本、存不了檔時照常遊戲、關於面板的連結，以及開場四幕（略過、中途重新整理）、營業日誌、第一封信只交一次、舊存檔直接進店。截圖存在 `tests/output/`（不進 git）。
