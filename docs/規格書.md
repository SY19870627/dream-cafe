# 夢想咖啡店 開發規格 v3（爽文系統版）

2026-11-10 · 線上版：https://claude.ai/artifact/8NSCDuaibhxscXGu5HnLCa（以線上版為準）

## 定位

女性上班族辭職後收到一封信，繼承一間老屋咖啡店。每天點一杯咖啡，德叔翻開筆記本一頁，她去完成一條夢想。遊戲約 60–90 分鐘玩完，網頁版，免費，只做繁體中文。

類型是台灣含蓄版爽文。玩法是爽文裡的「系統」：喝咖啡是任務，夢想是獎勵。遊戲世界裡的事都真實發生，沒有夢境或幻想段落；「白日夢」只用來形容類型。

跟第一版的差別：拿掉經營。第一版在抵達之後接經營系統，玩家辭掉工作又在遊戲裡上班。這一版沒有佈置、營收、溫度計、翻桌率、熟客管理、多店。

沿用第一版：開場（辭職信、邀請信、老屋、胖橘貓、德叔、環視）、德叔、龍眼、咖啡館色調、劇本拆檔、「避免 AI 味檢核表」、測試框架。

## 設計原則

新功能或新文本需遵守這些規則。

1. 主角不工作。沒有經營、營收、佈置任務、等待。事情發生在她身上。
2. 系統由德叔執行。不用彈窗，不用「任務完成」提示。德叔放下杯子說一句話。
3. 一杯換一條夢想。不重複，沒有稀有度、保底、貨幣、商店。
4. 動作可以重複，內容不能重複，三十條夢想各自不同。
5. 她只講實話，刺是對方自己聽出來的。主角不帶怨氣。
6. 場景裡的東西可以讓主角想起什麼，點到為止。
7. 互動模擬：每個互動對應那一刻的動作，寫信就打字，進門就推門。
8. 時空旅行的規則不解釋。

文本依本文末的「避免 AI 味檢核表」檢查。辭職信、第一次認出店裡的東西、最後看見老太太，這三場由作者起稿。

## 每杯咖啡的流程

點一杯咖啡，看德叔煮，喝完出門體驗那條夢想，回來帶一樣東西。店內沒有別的步驟。

1. 點餐：菜單三樣，點一樣。
2. 機關：30–60 秒動畫，不操作。
3. 喝：德叔說「今天的，請慢用。」
4. 出門：德叔翻開筆記本一頁，畫面切到那個地方。可環視，3–4 個可點物件。
5. 回店：帶回一樣東西或一個人。

送咖啡回公司等劇情事件由作者安排插入。第 0 天只有開場（辭職信、邀請信、老屋、龍眼、德叔、環視）。

## 爽文系統

四個零件，都由德叔以人的身分執行。玩家看不到數值。

| 零件 | 內容 | 規則 |
| --- | --- | --- |
| 任務 | 每天點一份餐點（咖啡必點，甜點可選） | 無失敗、無時限、無成本 |
| 咖啡因精神 | 喝完滿格，翻開夢想後歸零 | 1 杯＝1 條夢想，不累積；只是 UI 上的名稱 |
| 夢想清單 | 老太太的筆記本，第一版 30 條 | 不重複；順序全部固定，依劇本 |
| 收集 | 夢想圖鑑、餐點圖鑑、店內物件 | 翻閱用，沒有完成獎勵 |

夢想順序全部固定，依劇本。

不做：稀有度、保底、重複、貨幣、商店、每日登入、現實時間鎖、成就、排行、分享。

## 故事：三幕

謎底：老太太是未來的主角，德叔是她的伴侶。遊戲裡每個店外場景的角落她都在，玩家中後段才會注意到，回頭想前面的場景也有。結尾德叔只說一句確認她是誰的話，時空旅行怎麼回事不解釋。標題「我單方面辭退老闆後，開了一間夢想中的咖啡店」是字面上的事實。

第一幕（第 0–1 天）：寫辭職信，送出。信箱收到一封信，去咖啡店。老屋、龍眼、德叔、環視。德叔說店和一筆錢是一位老太太留下的，其他不說。辭職信由玩家自己打字或選句，送出有音效。

第二幕（第 2 天到約第 26 天）：一天一杯一條夢想。三條線同時走。

- 夢想線：回老家見父母、跟閨密碰面、在某個地方遇見前男友。場景裡的東西越來越像她的記憶。老太太越來越近。筆記本的筆跡慢慢變成她的。
- 公司線：送咖啡回公司三次（約第 3、12、20 天）。第一次她去送；第二次同事團購請她送；第三次真心同事下班自己來店裡。公司場景三次相同。
- 店線：帶回來的東西上架，路上遇到的人推門進來。龍眼從窗台移到她腿上。

第三幕（最後 3–4 天）：老闆推門進來點一杯，坐角落，看起來很累。主角請德叔多送一塊蛋糕，不說是誰給的。最後一天沒有夢想。主角環視店裡，老太太坐在角落，抬頭看她一眼。德叔說一句，確認她是誰。結局固定。

## 夢想清單內容規格

一條夢想是一個主角實際去到的場景，可環視。文字只附在物件上，點了才出現，每個物件一行。

| 欄位 | 說明 |
| --- | --- |
| 標題 | 筆記本上的一句話，老太太的口吻（「夏天在榻榻米上吃一碗冰」） |
| 場景 | 地點、季節、時間、光線、一個主音（雨、風鈴、暮爐、齒輪） |
| 底圖 | 一張 360 紙片場景，只畫三四樣東西 |
| 可點物件 | 3–4 個，各一行字，寫具體物件；其中一個像主角的記憶 |
| 過去的人 | 若有：誰、一句日常的話 |
| 老太太位置 | 必填。越後面越近。不可點，不標示 |
| 帶回店裡 | 一樣東西或一個人 |
| 互動 | 最多一個，對應那一刻的動作（推骨牌、把手伸向暮爐、翻一頁） |
| 階段 | 前／中／後 |
| 長度 | 1–2 分鐘 |

配比（30 條）：感官 9、機關 4、認出 7（公版默片、舊玩具、舊歌）、過去的人 7、新認識的人 3。

種子清單（作者已列）：

1. 下雨天在被窝裡看電視聽雨聲
2. 冬天在暖氣機出風口暖手（山上的中繼小屋）
3. 盯著寵物吃飯玩耗
4. 在咖啡廳讀一本書
5. 剛進店就聞到咖啡香
6. 夏天吃冰、一陣風、風鈴（日式老宅榻榻米）
7. 按下按鈕看齒輪轉，方糖掉進咖啡
8. 骨牌一排排倒下，聲音組成一首耶福能詳的歌（公版曲）
9. 牆上投影經典默片，看一眼就想起整部（卓別林、基頓、勞埃德，公版）

其餘 21 條由作者列。先寫感受，再找它發生的地方。自己去過的地方照記得的畫。

## 送咖啡回公司

全遊戲三次。它是劇情事件，不是每日任務，三次都是她自己想去的。主角騎機車、拿外送袋回去。

每次的結構：

1. 騎車過場 10 秒，同一段路
2. 櫃台對話：同事客套，主角講一句實話
3. 杯套上的「王」
4. 主角離開，不看反應
5. 同事慢半拍的笑

公司場景三次相同：同樣的燈、影印機聲、櫃台。

| 次數 | 天數 | 誰動 | 那一句 |
| --- | --- | --- | --- |
| 1 | 約第 3 天 | 主角去送 | 「你們要加班的時候跟我講，我送過來幫你們加油。」 |
| 2 | 約第 12 天 | 同事團購請她送 | 「反正我五點半就關門了，終於有空撼貓。」 |
| 3 | 約第 20 天 | 真心同事下班來店裡 | （不酸，請他坐） |
| 終 | 第三幕 | 老闆推門進來 | （主角不講話，多送一塊蛋糕） |

範例對話（第一次）：

> 「欸，聽說你開咖啡店喔？生意還好嗎？」 「還不錯啊。你們哧？」 「老樣子，上禮拜又弄到十一點。」 「辛苦了。」她把袋子放上櫃台。「這樣啦，你們要加班的時候跟我講一聲，我送過來幫你們加油，算便宜一點。」 「真的喔？」 「真的啊，反正我五點半就關門了，終於有空擼貓。」 同事笑了一下，笑得有點慢。 「對了，這杯是王經理的，他說要熱的。」

檢查：主角每句都能當真心話。「擼貓」是龍眼在公司線的第一次出現，同事之後到店看到貓會想起來。

## 互動對照表

給寫程式的 agent 用，避免它自行加按鈕或選單。手指只做四種事：點、拖曳、翻頁、看。

- 辭職信：打字或從幾句裡選，按送出，有聲音
- 進門：拖曳推門，風鈴才響
- 環視、找龍眼、最後看見老太太：拖曳 360，沒有提示
- 選位子、點餐、喝、翻頁出門：各一次點擊
- 機關：不操作
- 場景裡：一條夢想一個互動；點物件出一行字，像主角記憶的那個物件停一拍才出字
- 送咖啡對話：點下一句；那句實話不給選項，寫死
- 不存在：拖放佈置、數值、對話選項樹、計時、等待、自由時段

二選只在「說或不說」的時刻出現，兩邉都不會錯。

## 範圍切法

作者先把故事寫完，再開發。開發時先做驗證版，確認「點餐→機關→出門→回店」好不好玩，再做完整版。

| 版本 | 內容 | 目的 | 停損 |
| --- | --- | --- | --- |
| v3.0 驗證版 | 第一幕（沿用）+ 5 天 + 5 條夢想（種子清單前 5 條）+ 1 次送咖啡 + 機關 1 條路線。無結局 | 自己玩。問：第五天還想點餐嗎 | 自己玩到第三天就想關掉就停 |
| v3.1 完整版 | 30 條夢想、三幕、三次送咖啡、結局、圖鑑 | 可發布 | — |
| v3.2 | 更多夢想、進店的人的對話 | v3.1 有人玩完才做 | — |

驗證版不寫新規格、不重寫人物、不調色調。場景底圖用粗稿或 AI 生圖，機關先做一條路線。

不做：多店、其他語言、贊助以外的收費、現實時間留存、經營數值、佈置、多結局、成就、社群分享。

## 風險與對策

| 風險 | 對策 |
| --- | --- |
| 文本有 AI 味 | 關鍵場景作者起稿；每段過檢核表；予安台詞當基準 |
| 夢想變成公式 | 每條夢想一個不同的地方、一個不同的互動；公司線三次誰動不同 |
| 過去的人寫成和解劇 | 一句日常的話或打個招呼；不和解，不講道理 |
| 她的話聽起來像在酸 | 她講的是實話，不是反話；一趟一句 |
| 美術量失控 | 夢想場景只畫三四樣東西；驗證版先 5 張；咖啡館只改色溫 |
| 又變回上班 | 送咖啡固定三次；圖鑑無完成獎勵；不做「還差幾個」的 UI |
| 方向再變 | 先寫完故事，再做驗證版；停損條件見範圍切法 |
| 玩家猜到謎底 | 當認出寫，不當意外寫；中後段就讓人懷疑 |

## 劇情與對話寫作規則

開場四幕的台詞與律師信原樣沿用。其他對話重寫，寫完逐條對下面的檢核表，犯了就改，再給作者審。人物的說話方式以 `docs/人物誌.md` 為準。

### 避免 AI 味檢核表

1. 破折號用太多，普通的停頓也要加戲
2. 習慣用三個並列的排比句
3. 用「不是……而是……」製造其實不存在的對立
4. 每場戲都用一句空泛的金句收尾
5. 說完一件事，又再總結一遍
6. 情緒只用「很難過」之類的詞帶過，沒寫出角色當下的反應
7. 每句都完整工整，聽起來像輪流朗讀作文
8. 用老掉牙的比喻，或把不搭的意象混在一起
9. 所有角色講話都是同一個口氣
10. 讓角色替作者解說背景
11. 話中有話的地方全部講破
12. 一問一答太配合，每個人都像客服
13. 寒暄和交代場面的話太多，正經的對話遲遲不開始
14. 句子像公文或翻譯，抽象名詞一個接一個
15. 用形容詞和「非常」這類副詞取代具體細節
16. 同一件事換個說法再講一次，假裝劇情有推進
17. 為了去 AI 味，硬塞口語和口頭禪
18. 動作描寫和「他說」之類的說話標註太用力
19. 一件小事馬上被拉高成命運或永遠
20. 每場衝突都完整和解，沒有留下讓人想看下一次的東西
