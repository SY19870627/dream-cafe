## 一句話

**一小時的快餐式短篇：從一間空店開始，佈置、定菜單、設計咖啡，看客人被你的店吸引、變成熟客，最後店有了自己的樣子。**

## 為什麼這樣定

- 免費小品，網友願意玩一小時就很好，別指望玩家天天回來。
- 所以要設計的是**第一個小時**：玩家要在一小時內完整經歷一次「開一間夢想中的咖啡店」，有開始、有成長、有結尾。
- 第一版的教訓：沒有動詞、沒有回饋、真實時間讓連開發者都玩不到第四天。

## 已定案

| 項目 | 決定 |
| --- | --- |
| 平台 | 手機，直立操作；免費，只接受贊助 |
| 長度 | 主線約一小時，有片尾；之後店可以繼續開（可有可無的觀察箱） |
| 玩家要做的事 | 佈置、定菜單、設計咖啡。都在固定套路下發揮，套路要保證結果一定溫暖、文青、是玩家自己也想去的店 |
| 佈置的套路 | 分區模板：店分成窗邊、吧台、角落等區，每區有幾種精選擺法，再替換裡面的單品 |
| 咖啡設計的套路 | 四格組合：基底、豆子、風味、呈現各選一個，自動產生名字與描述 |
| 店自己產生變化 | 客人生態系為主：客人帶偏好標籤（安靜、植物、貓、黑膠、甜點…），被店的風格吸引、養成習慣、固定座位、彼此變熟；稀有訪客當驚喜；植物長大、牆上留言等「店會長大」當背景。手寫熟客故事只在條件成熟時出現，當點綴 |
| 營收 | 營收是氛圍的結果：看客人滿意度與來客數，來客數看氛圍，不看翻桌率；坐得越久越會留小費、口耳相傳。營收用來買擺飾 |
| 看得出因果 | 客人說出理由（「我是看到書牆才進來的」），加上圖鑑一格一格揭露每種客人的喜好 |
| 差異化 | 人的故事與台灣在地（台南東山、德叔、龍眼、熟客）＋ 坐進自己的店（3D 顧客視角） |
| 3D 顧客視角 | 佈置後一鍵坐下看；特別事件時被邀請坐下（「予安今天寫完了，要不要過來坐坐？」） |
| 時間 | 快轉預設開啟、不限速；主線一小時內走完開幕到滿一個月 |
| 片尾之後 | 店繼續開，離線也照跑，回來看德叔整理的「你不在的時候」；每天最多一則德叔口吻的溫和通知 |
| 停損 | 由你親自判斷：雛形玩一小時，無聊就砍 |

## 一小時的節奏（草案，待討論）

| 時間 | 發生什麼 |
| --- | --- |
| 0～10 分 | 開店、第一次佈置與定菜單、第一位客人上門並說出他為什麼進來 |
| 10～30 分 | 客群慢慢成形，第一次設計咖啡，第一位熟客出現 |
| 30～50 分 | 熟客之間變熟、稀有訪客、熟客故事的高潮，被邀請坐下看 |
| 50～60 分 | 店有了自己的樣子，徵店長、告別、片尾 |

## 開發規則（這次一定要守）

1. 先做能玩的雛形，用快轉一小時玩完，再決定要不要繼續。
2. 雛形階段不寫決策紀錄、不走審查流程、不做正式美術，程式可以丟。
3. 不把小細節展開成 A～D 選項請你決定；只問會改變方向的問題。
4. AI 負責主動質疑「這好玩嗎」，看到方向不對要喊停。
