# 我單方面辭退老闆後，開了一間夢想中的咖啡店｜遊戲企劃

> 本檔由 Claude Docs 的企劃文件匯出（2026-11-01），之後以本檔為準持續更新。

## 定位與核心承諾

這是一款療癒放置遊戲，讓台灣小資族不必真的掏出開店資金，也能擁有一間屬於自己的咖啡店，當成下班後暫時逃離上班疲憊的地方。

- **一句話定位**：下班後，回到你的咖啡店。
- **賣的不是經營，是「那間店」**：開店夢很好，資金是現實的；遊戲把現實留在門外，把浪漫還給老闆。
- **目標玩家**：想過辭職開咖啡店、但不會真的去開的上班族。
- **核心承諾**：你不欠這間店任何東西。沒有 KPI、沒有體力值、不會倒閉、不催你回來。
- **遊戲方向**：療癒放置，不走經營策略或連鎖擴張。
- **和競品的差異**：真實的台灣地點、在地咖啡與素材、有代入感的都市人熟客，以及一封辭呈開場。

開咖啡店是台灣上班族最常見的夢，也是最常被潑冷水的夢；這個「想要但不敢」的落差，就是這款遊戲的空間。

## 設計原則

玩家不是老闆，是「如果有這種店我一定天天去」的那個客人；他以客人的角度設計一家很酷、很讚的店，而遊戲的工作是一條都不砍。每個系統都要通過以下六條。

1. **以客人的角度設計夢想中的店**：這家店存在的理由是讓人想來，不是讓它賺錢。華而不實、製作耗時、菜單複雜、翻桌率低，這些反經營要素正是玩家的期待。
2. **錢不能打破夢想**：店不會因為不賺錢而變差或倒閉，遊戲裡也不出現「這杯不划算」這類提醒。
3. **遊戲本身就是逃離**：一次 15～30 分鐘，打開就能進店，不用先清任務。
4. **不能有上班的感覺**：不要 KPI、體力值、每日簽到壓力、催促推播。
5. **玩家被理解**：熟客裡有和玩家一樣累的上班族，偶爾也有客人反過來關心老闆。
6. **慢慢來**：不趕著開下一家店，每一站都待到店成為當地的一部分。

**反過來的經濟系統**

現實的老闆會一條一條砍掉的東西，在這裡都是加分；成長的單位是溫度（熟客的信任、牆上的回憶、菜單的來歷），不是營收。

| 現實裡會被砍掉的 | 遊戲裡換來什麼 |
| --- | --- |
| 不限時，一個人坐一整個下午 | 客人坐得越久，聊出越多故事 |
| 全店只有八個位子 | 每個位子都是好位子，座位視角更精緻 |
| 一杯虹吸要煮十分鐘 | 儀式感，老闆跟客人聊豆子的來歷 |
| 菜單二十頁、每杯都複雜 | 收藏感，每杯都是一段旅程 |
| 書牆、黑膠唱機、店貓睡在窗台 | 空間的靈魂，熟客會注意到 |
| 週休三天、下雨天提早打烊 | 打烊後模式與閒暇的獎勵 |

房租、隔壁開了連鎖店這類現實壓力，只能是一段劇情或一句對話，永遠不變成威脅店面存續的數字。

**要避開的陷阱**

- 為了留存率加入每日任務與限時活動，結果遊戲又變成一份上班。
- 開到第三、四家店後變成連鎖帝國：不設店數排行、總營收這類指標。
- 客人變成流水帳：一杯咖啡就走，只剩營收與成本。

## 世界觀與主線

這款遊戲同時往兩個方向走：世界要真實，夢要被保護。規則只有一句——**現實寫進故事，夢想寫進機制**；「溫度基金」是連接兩者的橋。

| 現實的部分（讓玩家相信） | 夢想的部分（讓玩家安心） |
| --- | --- |
| 真實的台灣站點、產區、食材與店家靈感 | 開店與營運的錢由溫度基金支付 |
| 開店成本會在對話與劇情裡出現（250 萬、「57 年天天喝咖啡」） | 成本永遠不會威脅店面存續 |
| 客人的人生困境是真的：加班、失業、離別 | 店裡總有一盞燈等著他們 |
| 華而不實的設計在現實中會倒閉 | 在這裡反而讓溫度升高 |

**主線：溫度基金**

1. **開場**：你遞辭呈那天，收到一封律師信。一位不認識的老先生留下「溫度基金」，條件只有一個：只要你的店讓人覺得溫暖，就持續撥款。不看營收，不看翻桌率。
2. **機制**：店裡掛著一支老溫度計，客人的笑容、留下的明信片、熟客的信任、動物夥伴的快樂，都會讓它慢慢升高，基金也照著撥款。
3. **主線謎題**：這位老先生是誰？為什麼選中你？每過一站，就收到一封他預先寫好的信，揭露一點過去。
4. **最後揭曉**：他年輕時也開過一家咖啡店，因為不賺錢，在最好的時候收掉了。他不希望再有人因為錢放棄這個夢；而他其實一直是坐在你第一家店角落的那位安靜熟客。

寫法上要讓玩家覺得是「繼承他的夢想」，不是「被包養」。主題只有一句：這個夢本來就不該被錢打破。

**可以一起存在的小設定**

- **咖啡土地公**：每家店供一尊小神像當彩蛋，老先生的信裡偶爾提到「祂也會幫你看著」。
- **待用咖啡**：客人可以預付一杯留給下一個需要的陌生人，是讓溫度計升高的一種方式。

## 玩法：咖啡管家與玩家

咖啡管家做好店裡所有的事，玩家不必做任何勞動，只以客人的角度設計與體驗這家店。

| 角色 | 負責的事 |
| --- | --- |
| 咖啡管家 | 研磨、沖煮、拉花、端杯、接待客人、照顧動物；每一步都花時間慢慢做，看他煮咖啡本身就是療癒 |
| 玩家 | 規劃動線與擺設、選位子坐下、喝咖啡、看客人的故事發生 |

- **動線就是玩法**：吧台、座位、擺飾怎麼放，決定管家走哪條路、客人坐哪裡、動物睡哪裡。
- **沒有「不夠快」的問題**：管家慢，是設計本身；客人會等，而且喜歡等。
- **沖咖啡用動作呈現**：溫杯、磨豆、悶蒸、注水、倒杯、端上都要看得到；對話泡泡只用在角色說話，不用來描述備餐步驟。
- **離線結算**：登入時用時間差結算營業時長與接待過的客人，由管家以「營業日誌」回報：誰來過、說了什麼、店貓換了哪個位子睡。
- **關鍵劇情等玩家在場**（建議）：熟客故事的里程碑不在離線時發生，管家會寫「他今天好像有話想說，但想等你在」，避免玩家錯過重要時刻。
- **管家的身份**（建議）：他是溫度基金派來的，年輕時在老先生的咖啡店當過學徒；他的回憶是主線謎題的另一半線索。

**溫度任務**

溫度就是任務目標：達成任務提升溫度，溫度帶來基金撥款，撥款用來佈置商店。

| 任務類型 | 例子 |
| --- | --- |
| 熟客故事 | 作家第一次說出他在寫什麼、工程師遞了辭呈、護理師終於坐下來 |
| 營業時長 | 開店滿 7 天、30 天、第一個梅雨季（離線時間也算） |
| 佈置 | 擺上 10 件擺飾、第一面書牆、做出一個「雨天座」 |
| 體驗 | 每個位子都坐過一次、在雨天坐窗邊喝一杯、以客人身份推門進店 |
| 菜單與在地 | 和在地農家變熟、收藏 5 杯站點飲品 |
| 動物夥伴 | 店貓第一次跳上你坐的那張椅子 |

任務不會有時限，也沒有每日任務；完成時由管家或客人的一句話告知，不跳出任務清單。

**經濟**

- 咖啡的成本只有時間，食材零成本。
- 錢只用來買家具、擺飾與主題佈置；擺放永遠免費。

**音樂**：慵懶輕柔的日系風格。（第一版試玩先用瀏覽器即時合成的電鋼琴代替，正式音樂的來源待定，見[開發計畫](./第一版開發計畫.md) Q11）

## 核心循環與大循環

小循環是每天下班回店裡營業、打烊；大循環是一站待到店成為當地的一部分，交棒給店長，再被客人邀請到下一站。

**循環流程**

1. 遞辭呈 → 收到溫度基金律師信
2. 來到新的一站 → 用在地素材佈置店面
3. 每日營業：3～5 位客人與故事
4. 打烊後：一個人待在店裡 → 隔天下班再回來（回到 3）
5. 待夠了不趕 → 店成了當地一部分，熟客故事走到結局
6. 徵店長、與熟客告別 → 店轉為常態經營
7. 以客人身份回訪：坐在自己設計的位子
8. 客人邀請：「來我家鄉看看」→ 下一站（回到 2）

- **營業時間跟著玩家走**：玩家設定自己的下班時間，店從那時開始營業，像有人幫你留了一盞燈。
- **徵店長、與熟客告別**：一站要結束時張貼徵才、面試店長（可以是熟客），再一一與熟客告別並交接，例如「我會常回來」；這是每位熟客故事線的結尾。咖啡管家跟著玩家前往下一站。
- **常態店不製造負擔**：不設「回來收錢」，店長偶爾寄明信片告訴你店裡近況。
- **客人模式**：推門進店、店員點單、聽別的客人聊這間店，親眼看見自己的作品。
- **終局**：一張「你的咖啡地圖」，台灣地圖上亮著你開過的每一家店。

## 客人與故事系統

客人不是來買咖啡的，是來過一段人生的，你的店剛好是他人生中的一站；系統重點是「關係」，不是「接待」。

**少而深**：每天只來 3～5 位客人，每位都值得停下來聽。經營數字淡化成「今天的店很溫暖」。

| 層級 | 數量 | 內容 |
| --- | --- | --- |
| 熟客 | 每站 8～12 位 | 完整人生線，分 5～7 章，跟著遊戲時間推進 |
| 過客 | 組合生成 | 一次性，但帶一個小故事：等面試的人、來躲雨的阿伯 |
| 季節客 | 依時節 | 中秋回鄉的遊子、畢業季學生、颱風夜受困的人 |

**咖啡是對話，不是商品**：客人說「今天被主管罵了，想要甜一點的」，咖啡管家會依他的心情慢慢煮出一杯回應；玩家坐在一旁，看故事怎麼走。

**客人會改變，也會離開**

- 寫稿的作家：從卡稿、投稿被退，到出書那天帶一本來送你。
- 翹班的工程師：從抱怨主管，到某天說他也遞了辭呈，最後可能成為店長。
- 每天外帶的護理師：某天終於坐下來，說今天是她第一次休假。
- 告別也是溫暖的一部分：有人搬去別的城市，幾年後帶著小孩回來。

**客人之間會交織**：作家和工程師在店裡認識、常客幫新客人出主意，店慢慢變成一個小社區。

**店會留下記憶**：客人留下的明信片、書、感謝卡掛上牆；玩上半年，這面牆就是你和客人的故事。

**技術做法**：故事節點用條件觸發（來店次數、你給過的回應、季節），不用固定日程；過客用「個性 × 心情 × 事件」組合生成，搭配少量手寫關鍵台詞。

## 空間系統

一個人待在店裡，是「擁有一間店」最真實的感覺；空間是主系統，不是背景。

**座位視角**

- 每個位子都能坐下，坐下後切換成那個位子的視角：吧台看磨豆機與手沖架、窗邊看街景與雨、角落沙發看整間店。
- 擺飾的擺放要考慮「從哪個位子看過去最好看」，視線設計本身就是玩法。
- 拍照／定格功能，存下玩家最喜歡的角度。

**光線與色溫**

- 燈具本身有色溫：2700K 暖黃愛迪生燈泡、3000K 軌道燈、自然光的窗。
- 時間與天氣改變光線：傍晚斜射的夕陽、梅雨季灰藍天光、夜裡只剩吧台一盞燈。
- 開燈、關燈、調亮度由玩家自己動手；關店前一盞一盞關燈是一種儀式。

**打烊後模式（招牌功能）**：客人都走了，只剩老闆一個人，可以整理擺飾、喝管家為你沖的今天最後一杯、寫一句今天的心情（「今天的一杯」咖啡日記）。沒有任何任務。

**聲音**：磨豆聲、熱水壺、黑膠唱片、窗外機車經過、雨打在鐵皮雨遮上。

**裝潢：讓玩家盡情試**

- 試擺不扣錢，確定了才算數，不滿意一鍵復原。
- 「買到」才是進度，「擺放」永遠免費；家具與擺飾都放在倉庫。
- 存多套佈置方案（夏天清爽版、冬天暖色版、聖誕版），一鍵切換。
- 熟客會注意到新裝潢：「這張沙發比較好坐，我可以多寫一小時。」

## 台灣在地站點

每一家店都是一個地方的章節，由三種在地素材組成：在地的味道→特色飲品、在地的建材→特色裝潢、在地的人→在地故事。下表「真實參考」欄來自已查證的資料，「遊戲構想」欄是設計提案。

**讓「不急著走」變成設計**

- 素材靠關係解鎖，不靠錢：和茶農變熟，他才分你今年最好的茶。
- 下一站由客人邀請：「你應該來我家鄉看看。」
- 飲品與擺飾可以帶走：東山學到的龍眼蜜特調，可以出現在下一家店的菜單上。
- 老街遊戲已做過的深坑、九份、關子嶺、東原，資料與美術可評估共用；關子嶺就在東山旁，可以串成同一區。

每一站仍需實地踏查才能寫故事；上表的店家與人物是靈感來源，遊戲中應改用虛構角色，或取得本人同意後再用真名。

## 菜單風格

只有咖啡不夠；菜單是店的個性，玩家從五種風格裡挑主軸、再混搭，每一種都連到不同的時段、客群與故事。

| 風格 | 真實參考 | 遊戲玩法 | 時段與客群 |
| --- | --- | --- | --- |
| 咖啡調飲吧 | 台南 T.C.R.C. 與 NO COFFEE 聯名，以耶加雪菲搭鐵觀音、洛神花，做出台南古早風味（[台灣英文新聞](https://www.taiwannews.com.tw/zh/news/5996686)）；台中 Coffee Stopover Black 用五支配方豆搭琴酒、威士忌設計咖啡調酒（[GQ Taiwan](https://www.hk01.com/旅遊/454119/台中酒吧-隱身-天上地下-7家在地潮人帶路才懂的秘密酒吧)） | 豆 × 基酒 × 在地素材的組合研發；每杯都有無酒精版 | 夜晚；下班後想微醺的上班族，最貼近遊戲定位 |
| 咖啡侍酒搭餐 | 國外已有五道菜的咖啡搭餐晚宴（[Philadelphia](https://phillymag.com/?p=3358438)）；UC Davis 研究發現果香咖啡配水果、麵包與堅果配什麼咖啡都好，而「熟悉度」是好搭配的最大因素（[ASIC 2025](https://www.alphavisa.com/asic/2025/documents/eposters/S8/S8_GUINARD.pdf)） | 像酒標的「杯測卡」（酸質、甜感、醇厚、香氣）；為熟客的餐點配一杯；解鎖「咖啡侍酒師」稱號 | 晚餐、週末；想把日子過得稍微講究的客人 |
| 在地食材 | 東山十果文創園區用龍眼蜜脆片做「脆脆蜂木拿鐵」（[工商時報](https://www.ctee.com.tw/news/20250505701326-431207)）；古坑有咖啡桶仔雞、拿鐵火鍋（[食尚玩家](https://supertaste.tvbs.com.tw/hot/325394)） | 每站靠關係解鎖食材，學到的配方可以帶到下一站 | 全天；在地人與過客 |
| 咖啡實驗室（類分子） | 分子調酒用凝膠、粉末、泡沫、霧化等手法改變風味與呈現（[Wikipedia](https://www.wikipedia.org/wiki/Molecular_mixology)）；Atomo 解析咖啡的上千種化合物、不用咖啡豆重組「分子咖啡」（[食力](https://www.foodnext.net/news/newsnation/paper/5357381195)） | 咖啡魚子醬、咖啡泡沫、煙燻罩等小遊戲；做出來的飲品有「驚喜度」 | 週末夜晚；科技宅、工程師熟客 |
| 咖啡下午茶 | 台南林百貨「林珈琲」以昭和復古空間配咖啡（[Trip.com](https://tw.trip.com/moments/poi-hayashi-department-store-23429067)）；東山龍眼乾曾幫吳寶春拿下世界盃麵包大賽（[食力](https://www.foodnext.net/issue/paper/5234840909)） | 咖啡配台式點心（桂圓麵包、鳳梨酥、豆花）的三層盤；與返鄉甜點師合作 | 週末午後；家庭、姊妹淘、約會的情侶 |

**菜單系統的原則**

- **菜單要和空間呼應**：調飲吧配昏暗吧台與 2700K 暖燈，下午茶配大窗與自然光；換菜單主軸，熟客會注意到。
- **時段變化**：午後下午茶 → 傍晚手沖 → 夜裡調飲，同一間店一天有三種表情；玩家下班後通常進到的是傍晚與夜晚。
- **研發是玩，不是考試**：管家負責試做，玩家負責試喝；食材零成本、只花時間，失敗的成品變成彩蛋台詞。
- **菜單連著故事**：單品通常由熟客一起研發，例如調酒師熟客、返鄉的甜點師、科技宅工程師。
- **每杯有自己的名字與來歷**：菜單上寫著這杯是在哪一站、和誰一起研發的，慢慢變成一本旅程菜單。

含酒精內容可能影響遊戲分級，上架前需確認分級規定；類分子飲品在遊戲中可以寫意，若要附真實食譜則需另外查證。

## 主題風格與動物夥伴

店的個性由三層自由組合：站點 × 主題 × 菜單，例如花蓮舞鶴的貓頭鷹茶園咖啡、大稻埕的偵探咖啡、東山的貓咪米倉咖啡。主題不只是外觀，它決定店裡的人、動物與故事類型。

| 主題 | 空間與裝潢 | 店員與夥伴 | 帶來的客人與故事 |
| --- | --- | --- | --- |
| 貓咪咖啡 | 貓跳台、窗台軟墊、高處通道 | 多隻店貓，各有個性與喜歡的位子 | 想養貓但租屋不能養的上班族 |
| 狗狗友善 | 戶外座、水碗、散步動線 | 店狗 | 帶狗散步的熟客、狗友聚會 |
| 奇珍異獸 | 溫室、生態缸、棲架 | 貓頭鷹、刺蝟、守宮、兔子…… | 生物系學生、怪得可愛的小眾愛好者 |
| 偵探咖啡 | 洋館書房、留聲機、線索板 | 偵探風制服 | 客人帶來小謎題，老闆陪著推理；可以做成「每週一案」 |
| 女僕咖啡 | 洋房、蕾絲、甜點櫃 | 女僕／執事制服、「歡迎回來」 | 想被好好款待的疲憊上班族 |
| 書店咖啡 | 一整面書牆、閱讀燈 | — | 寫稿的作家、讀書會 |
| 黑膠音樂 | 唱機、唱片牌、吧台 | — | 樂手、在唱片裡找回憶的人 |

**設計原則**

- **主題隨時可換**：就是一套佈置方案，可以混搭（貓咪 × 書店、偵探 × 黑膠）；換主題不會讓動物離開，牠們是家人。
- **動物是夥伴，不是商品**：各有名字、個性、喜歡的位子與會蹭的客人，也會隨裝潢改變睡覺的地方。
- **照顧本身就療癒**：打烊後餵食、梳毛、陪玩；動物有自己的休息區，可以拒絕互動。這同時也顧及在意動物福利的玩家（現實中貓頭鷹咖啡等奇異動物店曾有爭議）。
- **主題帶來故事類型**：偵探→謎題、女僕→款待、動物→陪伴、書店→創作；同一位熟客在不同主題的店裡會說不同的話。
- **在地動物可以跟著站點出現**：例如古坑林間的藍腹鷴（只來訪，不養）、部落的狗、老街的浪貓，讓野生動物成為站點的風景。

## 技術與製作

最大的工作量在文字與空間美術，不在程式；建議先用小原型驗證引擎與「玩家會不會捨不得客人」。

| 項目 | 決定 |
| --- | --- |
| 平台 | 手機，直立操作 |
| 美術 | 2D 插畫 |
| 收費 | 免費遊玩全部內容，只接受贊助 |
| 顧客視角做法 | B. 2.5D 紙片（已定） |

**用 2D 做出顧客視角的三種做法**

| 做法 | 怎麼運作 | 美術量 | 限制 |
| --- | --- | --- | --- |
| A. 牆面插槽（純 2D，可沿用 Phaser） | 店是四面牆加地板；佈置模式用斜角俯視；坐下時依座位朝向，顯示那面牆的正面圖，前景放桌面與杯子，用分層與縮放做出遠近 | 每件擺飾 2 張圖（佈置用＋正面） | 只能看正前方一面牆，角度固定 |
| B. 2.5D 紙片（2D 美術放進簡單 3D 房間） | 房間是 3D 盒子，家具與人物是 2D 插畫立牌；鏡頭可以放在任何座位，光線色溫可即時計算 | 每件擺飾 1～2 張圖 | 立牌從側面看會變薄，需要限制角度或讓立牌面向鏡頭 |
| C. 預繪每個座位 | 每個座位一張完整場景圖，擺飾為每個視角各畫一張 | 座位數 × 擺飾數 | 最美但美術量爆炸，不建議 |

已選 B。直立手機剛好適合顧客視角：畫面下方是桌面與咖啡杯，中段是客人與管家，上方是牆面與窗。B 在手機上的效能與立牌角度限制目前無法確定，需要實測；第一個原型（本 repo）做了同一間店、三個座位、五件擺飾。

**文字量估算**：12 位熟客 × 6 章，就是一部小說的分量，而且這只是一站。

**第一版範圍（已定案）**

1. 一站：台南東山。
2. 一～兩種主題、一種菜單風格。
3. 三位熟客的完整故事線，其中一位最後接手當店長。
4. 咖啡管家的沖煮動畫、動線與擺設、座位視角、離線結算與營業日誌。
5. 溫度任務與基金撥款的完整循環。
6. 律師信開場、第一封老先生的信、打烊後模式、一次客人模式。
7. 找幾位上班族朋友試玩，觀察他們是否想「回店裡看看」。
