## 定位與調性

故事前半是爽文，後半轉向無奈與面對，最後收在德叔身上。

- 只有一件超現實的事：年老的怡君會穿越到現在。其餘全部照現實走。
- 不限長度，以把故事講完整為準。結局的重量靠前面每一段事實疊起來。
- 爽點不給大錢。無痛繼承一間咖啡館，本身就是最大的爽點。
- 前半的爽要是真的爽，玩家才會喜歡怡君，後半才痛得起來。
- 感情重心在德叔這件事，留到一週目最後當爆點，中段不露。
- 全劇只有一次關鍵選項，通往兩個完全不同的結局。
- 遊戲名稱：一週目維持《我單方面辭退老闆後，開了一間夢想中的咖啡店》。

**爽文的範圍與原則**：從開場一直到前男友都是爽文。怡君的每一次打臉，都必須建立在玩家當下已經知道的事物上。做法是在同一場戲裡用敘事手法當下補充、當下打臉，不在前面預先鋪陳。

## 角色設定

### 陳怡君（年輕）

她在每一段關係裡都是備選，從來沒當過誰的第一順位。

- **個性**：透明像開水，刻苦耐勞，上司只會把工作壓給她。公司裡有兩個怡君。
- **說話**：只講實話、不酸人，每句話字面上都是好話。
- **工作**：業務助理。有一個案子她獨自做了很久，客戶的窗口都直接找她，但報告被經理拿去用。
- **家庭**：六歲時父母離婚，扶養權判給風流又忙碌的父親。衣食無缺，但沒時間交心。
- **感情**：渴望愛情。喜歡的男生都剛好喜歡上她身邊的女性朋友。深夜會忍不住滑交友軟體，遇到的人很快又離開。
- **感情觀**：不太會拒絕男性，覺得可以先交往再確認適不適合。因為總是第二選擇，有人接近就答應。交往時一直配合，最後反而被嫌沒有自己的想法而分手。
- **對德叔**：有點喜歡，分不清是父女情還是感情。
- **誤會**：以為摸龍眼才會有好運。
- **住處**：原本租在便宜的地段。只有第一晚因為迷路借住咖啡館，之後照常回租屋處，因為她跟德叔還不熟。

### 德叔

他帶著一段沒完成的願望在開店。

- **過去**：年輕時忙於工作。妻子身體不好，沒有子嗣。
- **妻子的願望**：在鄉下開一間咖啡館、養一隻貓，兩人在鄉下度過餘生。他沒能在她生前做到。
- **現在**：妻子走後回鄉下開店，店在台南東山的三合院，他直接住在裡面。
- **說話**：不是少言的人。他的話飽含知識而且溫暖，能裝下怡君的情緒。只有老老闆和自己的心事，他有所保留。
- **老老闆**：他對怡君說店是老老闆留給她的，所以在怡君眼中這是繼承。他口中的老老闆就是老怡君。
- **感情**：他明白年齡差距。他愛的是年老的她，願意照顧年輕的她。

### 老怡君

她是未來的怡君，一週目不出場，二週目才出現。

- 重病治療中。心裡的設定是癌症與化療，故事裡不講病名。
- 每次穿越過來的狀態都很慘。
- 原本那一生她沒有辭職，一直待在那間公司，這才像她。
- 原本那一生：上班後再也沒跟母親聯絡，最後一次見面是母親過世。去赴了網友的約，沒有人報警，留下病根，也因此被閨密看輕。這些都輕描淡寫，不具體。
- 起初不知道德叔在暗中幫年輕的自己，後來發現了，而且不同意。
- 龍眼喜歡她。

### 龍眼

開店後某天自己住進來的野貓，名字取自德叔妻子最愛吃的水果。

## 穿越規則

老怡君只有在身體撐不住的時候才過得來，她自己沒辦法選。這些規則不在遊戲裡解釋。

- **穿越的條件**：治療的反效果太強烈時才會被甩過來。身體好轉、反效果沒那麼強，就過不來。
- **回去的時機**：睡著之後消失。
- **過夜規則**：年輕的怡君在店裡過夜時，老怡君無法穿越過來。
- **同一個房間**：兩個怡君都住三合院右手邊護龍的同一間。她們沒辦法同時出現，所以住同一個地方很合理。
- **不碰面**：兩個怡君不見面。年輕的德叔不出現。時空悖論不討論。

## 德叔與老怡君

德叔把年輕的怡君照顧得越好，年老的她越健康，他就越見不到她。這是整個故事的哭點。

### 相遇

第一次是意外，之後兩人一起對出規律。這段放在二週目。

1. 夜裡，老怡君穿著醫院的病服、頭暈目眩地出現在三合院，被德叔發現。
2. 德叔扶她進門，倒水給她喝，她被嗆到，說請給我熱的。
3. 德叔情急之下端了剛泡好的熱咖啡，沒想到她喝了舒服很多。
4. 德叔問她怎麼來的。她說自己在醫院接受治療，不知道為什麼會在這裡。
5. 當晚德叔安排房間讓她睡。隔天早上她消失了，床看得出是睡到一半不見的。
6. 德叔覺得莫名其妙，老怡君以為自己做了一場夢。
7. 第二次、第三次治療之後，兩人發現了規律。

相處期間她提過自己住哪裡、在哪裡上班，德叔因此找得到年輕的怡君，寫了那封信。開場那天德叔剛好曬完棉被，是因為老怡君會來住。

### 德叔這一邊

- 老怡君每次來都太慘，所以他希望她身體變好。
- 照顧年輕的怡君是他單方面的行為。他一開始只知道她生病、單純想幫她，不知道這會影響見面。
- 他總有一天會發現代價。做這些事的煎熬全由他自己消化，怡君不會知道。

### 怎麼引路

- 帶來好事的不是好運，是德叔在替年輕的怡君引路。怡君誤以為是摸龍眼的關係。
- 德叔怎麼知道該幫什麼：都是老怡君講的。他不經意地跟她聊到，就能提前知道年輕怡君的狀況。
- 固定的儀式只有兩個：回咖啡館喝咖啡、摸龍眼。
- 引路的方式是每次不同的陰錯陽差，不是固定套路。沒有卡片。

## 一週目故事順序

一週目只演怡君的白天：開場 → 房東 → 公司 → 同事來店裡 → 前男友 → 家 → 閨密 → 吵架與網友 → 關鍵選項 → 結局。房東到前男友是爽，家與閨密是無奈與面對，吵架之後接到德叔。

### 1. 開場

1. 遊戲一開頭就是「我單方面辭退老闆」：發出辭職信。
2. 回家，在房間打開德叔的信再看一眼，然後出發。也就是說，信在她離職之前就已經看過了，只是玩家到這裡才知道。
3. 夜裡到店。門口是胖橘貓龍眼，德叔出面問好，說店是老老闆留給她的。
4. 回家時迷路，借住一晚。只有這一晚住在咖啡館。
5. 隔天早上照鏡子。

- **第一幕只有發出辭職信**，不預先交代公司的任何人事物。辦公室的所有事件，都留到送咖啡回公司那一場，當下補充、當下打臉。
- **理由**：第一幕是要讓玩家用第一人稱的視角，把自己填進去、親手遞出辭呈。這時候把怡君的故事加進來，遞辭呈的就不是玩家了。
- **夢與清醒**：「玩家就是我」的狀態一直持續到咖啡館與德叔見面，那時候也像在做夢；入宿三合院、睡著，都還在夢裡。第一次清醒的地方是照鏡子，玩家從這裡才開始意識到這是怡君的故事。
- **稱呼不改**：照鏡子之前，德叔對她說話一樣用「妳」。信的開頭第一行是她的名字，也留著。實際玩過，氣氛足以讓玩家理解。

### 2. 房東的打臉

第一天，緊接在借住那一晚之後。

1. 怡君從山上回到租屋處，先遇到房東。房東直接開口要房租，講難聽的話。
2. 她身上沒帶現金，賠不是之後先回房間。
3. 回房間找錢時翻出資料袋，發現那筆定存，去銀行確認。定存是她自己的錢：第一份工作那年開的戶，後來忘了，一直自動續存。
4. 回來付房租時打臉房東：錢付清，這次沒有道歉。
5. 之後搬家時，她主動說不租了。這是大的那一下，呼應辭職信的「單方面辭退」。

### 3. 送咖啡回原公司

這一場只放經理這一個爽點，暖意由同事的場面話來補。打臉的事一件一件來，不擠在一起。

**背景**（都在這一場當下補充，不在開場鋪陳）

- 她提辭職時還有特休沒休完，所以離職辦下來的那一天，就是送咖啡回去的日子。
- 德叔的說法是：可以好好宣傳咖啡館。
- 經理是直接把她功勞搶走的人。有個案子她獨自做了很久，窗口只找她，報告卻是經理拿去報。案子的具體內容未定。
- 辭職跑的是電子公文流程。經理把一整排待簽全選核准，根本沒看那封信，所以不知道她辭職了。
- 「我單方面辭退您」那句話寫在離職單的事由欄，一直在系統上，他只要點開就看得到。

**當天的流程**

1. 怡君回公司辦離職手續，順便送咖啡。
2. 在人資那裡，怒氣沖沖的經理跑來罵她到底人去哪了，話講得很難聽。
3. 怡君說她是來辦離職手續的。經理說怎麼沒提前通知。
4. 人資佐證：經理已經簽過了。
5. 她回到辦公室，經理已經不在，可能躲起來了。
6. 她請大家喝咖啡，順便宣傳咖啡館，也送了不少濾掛式咖啡包。
7. 她在經理座位放了一杯店裡的新產品「銀杏龍眼咖啡」，留下一張紙條：希望經理喝完能提神、過目不忘。紙條表面說好話，實際是打臉。這是伏筆，之後成為同事到咖啡館的談資。
8. 最後她回到座位，把小綠拿到窗邊。窗邊座位的同事說會幫忙照顧。

銀杏龍眼咖啡是德叔推薦她帶去的。怡君自己也不明白，為什麼會這麼剛好。

### 4. 同事來店裡

- 同事與前男友一起來店裡。這一次只打同事的臉。
- 窗邊那位同事根本忘了小綠，連來到咖啡館也沒想起這件事。小綠其實是前男友自己在照顧。
- 前男友這次沒有帶小綠。

### 5. 前男友

- 前男友事後私下帶著小綠，單獨來找怡君。這是他約她的理由。
- 怡君到這時才知道小綠還活著，而且長大了。
- 這時的怡君已經煥然一新，變好看、有自信，談吐之間都是對未來的期待。
- 他開口問能不能回到過去，怡君說需要時間想想。對白見「作者親寫台詞」。
- 怡君是真的不知道要不要答應。她以前都會答應，這次卻猶豫了。
- 前男友在這之後反而沒再聯絡。他自尊心強，以為自己低聲下氣就能得到她，而她猶豫了，這就已經不是他要的答案。
- 打臉不是她開口拒絕，是她的猶豫本身：當初嫌她沒想法的人，受不了她真的開始想。
- 德叔看在眼裡，跟她說：這個小夥子大概被妳傷透心了。
- 由這裡引出怡君的戀愛煩惱。

### 6. 家：母親與父親

母親線與父親線講的是同一件事，合成一段。

**為什麼去看母親**

- 老怡君跟德叔提過，自從上班後就再也沒跟母親聯絡，最後一次見面是母親過世。
- 德叔想替她圓這件事，建議怡君可以去見見母親。
- 所以是怡君自己找上門，母親在門口措手不及。

**母親門口**

- 門後有人喊媽媽。母親要小男孩跟大姐姐打招呼，說她是某個朋友的女兒。
- 怡君受傷，回去怪父親當初為什麼要離婚，害她有一個這樣的家。

**父親與阿姨**

- 回到自己真正的家，看到的是父親與阿姨。
- 父親認不得她，把她認成了她的母親。她的反應是疑惑。
- 阿姨在旁邊，這讓她冷靜下來，好好看這個已經年邁的父親。
- 被怪罪時，父親不辯解，轉身去拿錢。
- 父親跟母親當年的故事，由阿姨說出來。
- 調性：她對父親的火氣不該太大。父親線走的是世間無常的遺憾，生氣要留給德叔。

**德叔的開導**

- 阿姨講的話，年輕的怡君聽不懂，她回去問德叔。
- 之後她會自己疑惑什麼是愛。這個答案，最後是在德叔身上看到的。

### 7. 閨密

放在家之後、網友段之前，當作網友段的鋪陳。這一場的內容還沒定。

### 8. 吵架與網友

- 老怡君發現德叔在暗中幫年輕的自己，兩人在病情與見面上意見分歧。這一半一週目看不到。
- 氣頭上的德叔看到年輕的怡君，直接念她不愛惜自己的身體。
- 怡君也生氣了：「連我爸都不會這樣管我，你有什麼資格。」
- 這時剛好接上網友約她見面。

### 會在某一天出現的小事

- 某一天她發現雀斑消失了，原因是德叔的幫忙讓她身體變好。
- 小綠之後再出現一次，讓玩家再暖心一次。

## 關鍵選項與兩個結局

全劇唯一的選項是：吵架之後，要不要去赴網友的約。一週目走「沒赴約」，「赴約」在二週目才能選。

| | 結局一：沒赴約 | 結局二：赴約 |
| --- | --- | --- |
| 網友那件事 | 網友找到店裡來糾纏，德叔報警化解 | 網友帶她去開房間並下藥，她極力反抗。德叔報的警及時趕到，但她留下病根 |
| 怡君之後 | 因為害怕，住進三合院 | 住院 |
| 老怡君 | 身體好轉，不再來 | 病得夠重，還會來，跟德叔走完一生 |
| 德叔 | 一個人老去。生病後，在病床上向年輕的怡君坦白一切 | 有她相伴 |

- 選項之後直接接結局，中間不必多交代。
- 結局二是玩家代替怡君選的，跟德叔無關，他不必為此負責。
- 旅館那段不正面演：寫到她發現不對、開始掙扎，就切到敲門聲，之後只演事後。

### 網友那一晚的三個版本
