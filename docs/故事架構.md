# 咖啡店角色設定與故事架構（完整版，2026-11-17）

> **這份是故事架構，不是規格。** 內容是 2026-11-15 到 11-17 定案的角色設定、一週目與二週目的因果鏈，並併入 11-17 劇本 v4.7 到 v4.9 的決定。
> `docs/規格書.md` 的定位（從頭到尾都在爽）確定要改，但要等故事寫完再動。
> 兩份文件衝突時，故事方向與人物設定以這份為準；玩法與程式結構仍以規格書為準。

這份只收作者點頭過的設定。討論中由 AI 提出、作者還沒點頭的，全部集中在「尚未確認的提案」一節，不算設定。
標成「作者親寫」的句子一字不改。

## 定位與調性

故事前半是爽文，後半轉向無奈與面對，最後收在德叔身上。

- 只有一件超現實的事：年老的怡君會穿越到現在。其餘全部照現實走。
- 不限長度，以把故事講完整為準。結局的重量靠前面每一段事實疊起來。
- 爽點不給大錢。無痛繼承一間咖啡館，本身就是最大的爽點。
- 前半的爽要是真的爽，玩家才會喜歡怡君，後半才痛得起來。
- 感情重心在德叔這件事，留到一週目最後當爆點，中段不露。
- 全劇只有一次關鍵選項，通往兩個不同的結局。兩個結局都是離別。
- 遊戲名稱：一週目維持《我單方面辭退老闆後，開了一間夢想中的咖啡店》。

### 爽文的寫法

從開場一直到前男友都是爽文。

- **建立在已知的事物上**：怡君的每一次打臉，都必須用玩家當下已經知道的東西。
- **當下補充、當下打臉**：需要的背景在同一場戲裡用敘事補一句，馬上翻盤，不在前面預先鋪陳。
- **一件一件來**：每場只放一個爽點，不擠在一起。
- **溫和的爽**：打臉未必要真的對對方做了什麼。對方照舊習慣來找她，她只是告知現在的狀況，對方的驚訝和態度轉變本身就是爽點。
- **不逐天演起床、睡覺**。

## 角色設定

### 陳怡君（年輕）

她在每一段關係裡都是備選，從來沒當過誰的第一順位。

- **個性**：透明像開水，刻苦耐勞，上司只會把工作壓給她。公司裡有兩個怡君。
- **說話**：只講實話、不酸人，每句話字面上都是好話。
- **工作**：業務助理。有一個案子她獨自做了很久，客戶的窗口都直接找她，但報告被經理拿去用。
- **家庭**：六歲時父母離婚，扶養權判給風流又忙碌的父親。衣食無缺，但沒時間交心。
- **感情**：渴望愛情。喜歡的男生都剛好喜歡上她身邊的女性朋友。深夜會忍不住滑交友軟體，遇到的人很快又離開。
- **感情觀**：不太會拒絕男性，覺得可以先交往再確認適不適合。因為總是第二選擇，有人接近就答應。交往時一直配合，最後反而被嫌沒有自己的想法而分手。
- **對德叔**：有點喜歡，分不清是父女情還是感情。
- **誤會**：以為摸龍眼才會有好運。
- **住處**：原本租在便宜的地段。只有第一晚因為迷路借住咖啡館，之後照常回租屋處，因為她跟德叔還不熟。

### 德叔

他帶著一段沒完成的願望在開店。

- **過去**：年輕時忙於工作。妻子身體不好，沒有子嗣。
- **妻子的願望**：在鄉下開一間咖啡館、養一隻貓，兩人在鄉下度過餘生。他沒能在她生前做到。
- **現在**：妻子走後回鄉下開店，店在台南東山的三合院，他自己也住在這間三合院。
- **說話**：不是少言的人。他的話飽含知識而且溫暖，能裝下怡君的情緒。只有老老闆和自己的心事，他有所保留。
- **老老闆**：他對怡君說店是老老闆留給她的，所以在怡君眼中這是繼承。他口中的老老闆就是老怡君。他平常就叫年輕的怡君「老闆」。
- **感情**：他明白年齡差距。他愛的是年老的她，願意照顧年輕的她。

### 老怡君

她是未來的怡君，一週目不出場，二週目才出現。

**她是什麼樣的人**

- 她是一個最希望一切能重來的人。
- 她感嘆自己這一生沒有發生任何高潮迭起的事，所有事情就像 AI 寫的流水帳，沒有任何意外，是一眼看到頭的人生。
- 自從網友那件事之後，她再也不相信男生。
- 她身上背著很多遺憾，常想「當時如果能怎麼樣該有多好，人生就會改變」。
- 德叔是她這輩子唯一的例外。這也是為什麼她寧願自己忍受病痛，也希望見德叔一面。

**原本那一生**（都輕描淡寫，不具體）

- 沒有辭職，在那間公司做了二十幾年，最後被資遣，因為上司不喜歡她。
- 上班後再也沒跟母親聯絡，最後一次見面是母親過世。
- 去赴了網友的約，沒有人報警，留下病根，也因此被閨密看輕。

**現在的她**

- 重病治療中。心裡的設定是癌症與化療，故事裡不講病名。
- 每次穿越過來的狀態都很慘。
- 起初不知道德叔在暗中幫年輕的自己，後來發現了，而且不同意。
- 龍眼喜歡她。

**她為什麼被德叔打動**：第一次穿越的那個晚上，德叔主動做了一連串的事，還安排住處讓她睡。對一個又老又病的人來說，這一連串的溫暖就足以打動人心，不需要另外的理由。而且玩家早就透過年輕怡君第一晚的內容，親身體驗過這份溫暖了。

### 龍眼

開店後某天自己住進來的野貓，名字取自德叔妻子最愛吃的水果。

## 穿越規則

老怡君只有在身體撐不住的時候才過得來，她自己沒辦法選。這些規則不在遊戲裡解釋。

- **穿越的條件**：治療的反效果太強烈時才會被甩過來。身體好轉、反效果沒那麼強，就過不來。
- **回去的時機**：睡著之後消失。
- **時間**：未來的時間與現在的時間是兩條平行線，未來過一天，現在也過一天。
- **治療時程表**：老怡君給過德叔她的治療時程表，所以德叔知道她哪一天應該會來。
- **過夜規則**：年輕的怡君在店裡過夜時，老怡君無法穿越過來。
- **同一個房間**：兩個怡君都住三合院右手邊護龍的同一間。她們沒辦法同時出現，所以住同一個地方很合理。
- **不碰面**：兩個怡君不見面。年輕的德叔不出現。時空悖論不討論。

## 德叔與老怡君

德叔把年輕的怡君照顧得越好，年老的她越健康，他就越見不到她。這是整個故事的哭點。

### 相遇

第一次是意外，之後兩人一起對出規律。這段放在二週目的開頭。

1. 夜裡，老怡君穿著醫院的病服、頭暈目眩地出現在三合院，被德叔發現。
2. 德叔扶她進門，倒水給她喝，她被嗆到，說請給我熱的。
3. 德叔情急之下端了剛泡好的熱咖啡，沒想到她喝了舒服很多。
4. 德叔問她怎麼來的。她說自己在醫院接受治療，不知道為什麼會在這裡。
5. 當晚德叔安排房間讓她睡。隔天早上她消失了，床看得出是睡到一半不見的。
6. 德叔覺得莫名其妙，老怡君以為自己做了一場夢。
7. 第二次、第三次治療之後，兩人發現了規律。

相處期間她提過自己住哪裡、在哪裡上班，德叔因此找得到年輕的怡君，寫了那封信。開場那天德叔剛好曬完棉被，是因為老怡君會來住。

### 德叔這一邊

- 老怡君每次來都太慘，所以他希望她身體變好。
- 照顧年輕的怡君是他單方面的行為。他一開始只知道她生病、單純想幫她，不知道這會影響見面。
- 做這些事的煎熬全由他自己消化，年輕的怡君不會知道。

### 怎麼引路

- 帶來好事的不是好運，是德叔在替年輕的怡君引路。怡君誤以為是摸龍眼的關係。
- 德叔怎麼知道該幫什麼：都是老怡君講的。
- 固定的儀式只有兩個：回咖啡館喝咖啡、摸龍眼。
- 引路的方式是每次不同的陰錯陽差，不是固定套路。沒有卡片。

### 德叔出手的四件事

德叔在一週目每出手一次，背後都有一句老怡君講過的話。二週目會看到這些夜晚。

| 德叔做的事 | 老怡君說過的話 |
| --- | --- |
| 寫信叫她辭職 | 她笑著說自己在公司做了二十幾年，但公司最後還是把她資遣了，上司不喜歡她 |
| 推薦她帶銀杏龍眼咖啡去公司 | 上司不喜歡她的原因：有件事她記得很清楚，是上司自己搞錯了，但她不好解釋什麼，就被上司記仇了 |
| 建議她去見母親 | 上班後再也沒跟母親聯絡，最後一次見面是母親過世 |
| 網友那晚報警 | 她去赴了約，沒有人報警 |

房東和前男友那兩段不需要德叔出手。那是怡君成長後的必然結果：房東是因為她有底氣，前男友是因為她有自信。

## 一週目故事順序

一週目只演怡君的白天：開場 → 房東 → 公司 → 同事來店裡 → 前男友 → 家 → 閨密 → 吵架與網友 → 關鍵選項 → 結局。房東到前男友是爽，家之後是無奈與面對，吵架之後接到德叔。

### 1. 開場

1. 遊戲一開頭就是「我單方面辭退老闆」：送出電子離職單。事由欄固定是「從今天起，我單方面辭退您。」，沒有三選一。交接配合特休。
2. 回家，在房間裡把舊信再看一遍，然後出發。信在她離職之前就已經看過了，只是玩家到這裡才知道。
3. 天黑到店（「夜裡，東山。」）。門口是胖橘貓龍眼，德叔出面問好，說店是老老闆留給她的。
4. 回家時迷路，借住一晚。只有這一晚住在咖啡館。德叔說他自己也住在這間三合院。
5. 隔天早上照鏡子。

- **第一幕只有送出離職單**，不預先交代公司的任何人事物。辦公室的所有事件都留到回公司那一場。
- **理由**：第一幕是要讓玩家用第一人稱的視角，把自己填進去、親手遞出辭呈。這時候把怡君的故事加進來，遞辭呈的就不是玩家了。
- **夢與清醒**：「玩家就是我」的狀態一直持續到咖啡館與德叔見面，那時候也像在做夢；入宿三合院、睡著，都還在夢裡。第一次清醒的地方是照鏡子，玩家從這裡才開始意識到這是怡君的故事。
- **稱呼不改**：照鏡子之前，德叔對她說話一樣用「妳」。信的開頭第一行是她的名字，也留著。
- **德叔開場已核准的短句都不動。** 「吃過再走。」這一句刪掉。
- **鑰匙**：德叔把鑰匙交給她（作者親寫，見台詞一節）。

### 2. 房東的打臉

第一天，緊接在借住那一晚之後。

1. 怡君從山上回到租屋處，先遇到房東。房東直接開口要房租，講難聽的話。
2. 她身上沒帶現金，賠不是之後先回房間。
3. 回房間找錢時翻出資料袋，發現那筆定存，去銀行確認。定存是她自己的錢：第一份工作那年開的戶，後來忘了，一直自動續存。
4. 回來付房租時打臉房東：錢付清，這次沒有道歉。
5. 之後搬家時，她主動說不租了。這是大的那一下，呼應離職單的「單方面辭退」。

劇本上的決定：存摺那一段只留〔把存摺放上吧台〕那一支，拿掉按鈕，岔路照留。

### 3. 回原公司（第三天）

這一場只放經理這一個爽點，暖意由同事的場面話來補。

**背景**（都在這一場當下補充）

- 她提辭職時還有特休沒休完，所以離職辦下來的那一天，就是回公司的日子。
- 她不帶咖啡下山，帶的全部是濾掛式咖啡包。濾掛包是店裡本來就有的，德叔平常包好放著。
- 德叔的說法是：可以好好宣傳咖啡館。
- 有個案子她獨自做了很久，窗口只找她，報告卻是經理拿去報。這個案子就是老怡君說的那件事：她記得很清楚，是上司自己搞錯了，但她不好解釋。現有劇本會議室那個案子留著當素材。上司具體搞錯了什麼還沒定。
- 辭職跑的是電子公文流程。經理把一整排待簽全選核准，根本沒看，所以不知道她辭職了。
- 「從今天起，我單方面辭退您。」那句話一直在系統上的事由欄，他只要點開就看得到。

**當天的流程**

1. 怡君回公司辦離職手續，帶著濾掛式咖啡包。
2. 在人資那裡，怒氣沖沖的經理跑來罵她到底人去哪了，話講得很難聽。
3. 怡君說她是來辦離職手續的。經理說怎麼沒提前通知。
4. 人資佐證：經理已經簽過了。
5. 她回到辦公室，經理已經不在，可能躲起來了。
6. 她把濾掛包發給大家，順便宣傳咖啡館。
7. 她在經理座位放了一包店裡的新產品「銀杏龍眼咖啡」濾掛包。外包裝上寫著「提神醒腦，過目不忘」。她沒有留紙條，那不是怡君會做的事。這是伏筆，之後成為同事到咖啡館的談資。
8. 最後她回到座位，把小綠拿到窗邊。坐窗邊的宜蓁說會幫忙照顧。

銀杏龍眼咖啡是德叔推薦她帶去的。怡君自己也不明白，為什麼會這麼剛好。

**經理的反應**：經理看到包裝上的字很生氣，戲劇性地把那包濾掛咖啡抓起來丟在地上，然後出糗。這就是包裝上要有那八個字的原因。怡君當時不在場，是同事後來到店裡轉述的；但遊戲中會實境展示這段過程，而且要講得很好笑。他怎麼出糗，後面再定。

### 4. 同事來店裡

- 同事與前男友一起來店裡。這一次只打同事的臉。
- 同事把經理摔咖啡的事當笑話講給她聽。他們對銀杏龍眼咖啡讚不絕口，每個人都說要訂一盒放公司。
- 德叔是始作俑者，所以這包咖啡的事由他來回答最戲劇。他必須回答出老紳士的答案，但又讓這群年輕人笑到不行。他的話由作者寫。
- 大家以為德叔是老闆、怡君是職員。因為怡君之前還送咖啡包給大家，這個印象更容易讓人誤會。
- 結果德叔稱呼怡君「老闆」，這就是落差。怡君沒有對任何人做什麼。
- 宜蓁根本忘了小綠，連來到咖啡館也沒想起這件事。小綠其實是前男友自己在照顧。
- 前男友這次沒有帶小綠。

### 5. 前男友

- **雀斑與氣色**：放在前男友單獨來之前。某一天她照鏡子，發現雀斑消失了，原因是德叔的幫忙讓她身體變好。這一場的鏡子怎麼演，跟前男友那幾場一起定。
- 前男友事後私下帶著小綠，單獨來找怡君。這是他約她的理由。
- 怡君到這時才知道小綠還活著，而且長大了。
- 這時的怡君已經煥然一新，變好看、有自信，談吐之間都是對未來的期待。
- 他開口問能不能回到過去，怡君說需要時間想想。對白見「作者親寫台詞」。
- 怡君是真的不知道要不要答應。她以前都會答應，這次卻猶豫了。
- 前男友在這之後反而沒再聯絡。他自尊心強，以為自己低聲下氣就能得到她，而她猶豫了，這就已經不是他要的答案。
- 打臉不是她開口拒絕，是她的猶豫本身：當初嫌她沒想法的人，受不了她真的開始想。
- 德叔看在眼裡，跟她說：這個小夥子大概被妳傷透心了。
- 由這裡引出怡君的戀愛煩惱。

### 6. 家：母親與父親

母親線與父親線講的是同一件事，合成一段。

**為什麼去看母親**

- 德叔想替她圓一件事，建議怡君可以去見見母親。
- 所以是怡君自己找上門，母親在門口措手不及。

**母親門口**

- 門後有人喊媽媽。母親要小男孩跟大姐姐打招呼，說她是某個朋友的女兒。
- 怡君受傷，回去怪父親當初為什麼要離婚，害她有一個這樣的家。

**父親與阿姨**

- 回到自己真正的家，看到的是父親與阿姨。
- 父親認不得她，把她認成了她的母親。她的反應是疑惑。
- 阿姨在旁邊，這讓她冷靜下來，好好看這個已經年邁的父親。
- 被怪罪時，父親不辯解，轉身去拿錢。
- 父親跟母親當年的故事，由阿姨說出來。
- 調性：她對父親的火氣不該太大。父親線走的是世間無常的遺憾，生氣要留給德叔。

**德叔的開導**

- 阿姨講的話，年輕的怡君聽不懂，她回去問德叔。
- 之後她會自己疑惑什麼是愛。這個答案，最後是在德叔身上看到的。

### 7. 閨密

放在家之後、網友段之前，當作網友段的鋪陳。閨密是唯一一個被連環爆擊的角色，等於把前面的爽點重走一遍。

1. 閨密照老習慣臨時約她，怡君說今天不行。她從來沒拒絕過閨密，這次也不是故意的，只是店要顧。閨密在 LINE 上驚訝地回她（作者親寫）。
2. 閨密說要去找她，問她在哪。怡君回答之後，閨密疑惑她在那種鄉下地方做什麼。
3. 怡君只回「在上班」。閨密說找人載她過去，要怡君等她。
4. 過一段時間後，閨密到了咖啡館。這裡走跟同事那次類似的橋段：她驚訝怡君是老闆。
5. 再來怡君講到前男友，閨密再驚訝一次。在閨密的認知裡，怡君是有人要就會點頭的人。

### 8. 吵架與網友

**吵架那一晚**（一週目看不到）

1. 老怡君看到房間裡有小綠，問德叔這是什麼。
2. 德叔這才跟她解釋來龍去脈。他甚至認為自己很對：他是在幫她獲得健康的身體。
3. 在這之前，兩人就已經知道她穿越過來的原因是治療。
4. 老怡君第一次跟德叔吵架，吵得很強烈。她說了一句重話（作者親寫），然後回房間把自己關起來。
5. 德叔也在氣頭上，覺得老怡君根本不愛惜自己的身體。
6. 或許就在這時候，老怡君才明白自己愛上了德叔。

**一週目看到的部分**

- 氣頭上的德叔看到年輕的怡君，直接念她不愛惜自己的身體。
- 怡君也生氣了（作者親寫）。
- 這時剛好接上網友約她見面。

## 關鍵選項與兩個結局

全劇唯一的關鍵選項是：吵架之後，要不要去赴網友的約。一週目走「沒赴約」，「赴約」在二週目才能選，到了那個地方直接出現讓玩家選。

| | 結局一：沒赴約 | 結局二：赴約 |
| --- | --- | --- |
| 網友那件事 | 網友找到店裡來糾纏，德叔報警化解 | 網友帶她去開房間並下藥，她極力反抗。德叔報的警及時趕到，但她留下病根 |
| 年輕的怡君 | 因為害怕，住進三合院 | 住院。出院後也搬到三合院住，由德叔照顧 |
| 老怡君 | 身體好轉，不再來。兩人吵完那一架就再也沒見 | 穿越過來後奇蹟地能過夜，再也沒回到未來，因為她已經癌末擴散。幾天後，她睡在床上死去 |
| 德叔 | 一個人老去。最後把怡君叫來，問她願不願意聽 | 陪了她幾天，直到她離開。之後照顧年輕的怡君，最後交代遺言 |

- 選項之後直接接結局，中間不必多交代。
- 結局二是玩家代替怡君選的，跟德叔無關，他不必為此負責。
- 結局二雖然成全了德叔與老怡君，但他們的幸福只維持幾天。
- 旅館那段不正面演：寫到她發現不對、開始掙扎，就切到敲門聲，之後只演事後。

### 網友那一晚的三個版本

- **沒有德叔的原本那一生**：她去赴約，沒有人報警，最壞的情況發生了，從此留下病根。
- **赴約**：德叔報的警及時趕到，擋掉了最壞的情況，但還是留下病根。
- **沒赴約**：整件事被擋在外面。

### 一週目的結尾就是二週目的入口

- 德叔把怡君叫來，問她願不願意聽他說一件事（作者親寫）。
- **玩家選「是」**：直接進入二週目，開頭直接接上老怡君的穿越。德叔開始講的所有內容，就是二週目。
- **玩家選「否」**：德叔說那就下次吧，一週目到這裡結束，回到標題畫面。之後玩家可以回到這一刻，他還在那裡問同一句話。
- 原本「病床上向怡君坦白一切」那場戲，由整個二週目取代。

## 二週目

二週目是德叔說給怡君聽的完整時間線：把他與老怡君的見面穿插到整個遊戲裡，讓玩家一次看懂前因後果。

- **開頭**：老怡君第一次出現的那一晚，再接到德叔寄出那封信。信是誰寫的、為什麼寄給怡君，都在這裡交代。
- **開頭標題**：從一週目的「我單方面辭退老闆後，開了一間夢想中的咖啡店」，改成「妳單方面辭退老闆，繼承一家咖啡館」。
- **相遇段的表現**：用圖讓玩家感受，只搭配極簡單的話，不用文字說明。
- **夜晚的內容**：見「德叔出手的四件事」，以及吵架那一晚。
- **最後回到那個選擇**：玩家這次可以選赴約。
