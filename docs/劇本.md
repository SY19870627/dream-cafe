**設計說明 G1：通用提示規則**（所有「可以點／拖」的互動共用一套，不各做各的；21:01 改成發光加箭頭）
- 一進這句：目標物外圈有柔和的呼吸光圈（跟現在椅子熱點的光一樣），不閃爍，並加上箭頭指著目標物。拖曳類（鑰匙）則物品發光，箭頭指向要拖去的地方。
- 同時，閱讀框上方出現一行短提示，樣式跟原本信箱的「點信箱，把信封拿出來。」一樣，例如「摸摸龍眼」「點椅子坐下」「點床躺下」「把鑰匙拿給德叔」。
- 不做 3 秒後才出現的小手示範。
- 不做也能往下的互動，提示後面加小字「（也可以直接翻頁）」；必做的（椅子）不加。
- 做過或翻頁後，光圈、箭頭和提示都消失。點目標的那一下不算翻頁，避免玩家點貓結果跳到下一句。

我：「……德叔如果是認真的呢？」

我：「說不定真的能順利繼承。」

我：「那就不用再聽別人指揮做事情了。」

我：「可是我什麼都不懂，連咖啡都不會泡。」

我：「……不會泡，可以學。」

我：「有那十六萬，可以先撐一陣子。」

我：「可是撐完了以後呢？」

我：「從以前到現在，都是別人叫我做什麼，我就做什麼。」

我：「現在要我自己拿主意，我還真的不知道要怎麼辦。」

（互動：這裡停一拍，玩家點一下才繼續。）

我：「……可是如果不去，我大概會一直想這件事。」

我：「不然……先試試看好了。」

我：「先當實習的老闆試試看，不適合再說。」

我：「明天就回去找德叔吧。」

（字卡：第二天）

# 第二天　回咖啡館

（畫面：第二天，咖啡館。）

戶頭裡有十六萬，我才敢回來這裡。

德叔在吧台後面擦杯子，今天吧台上是空的。

（互動：玩家點包包裡的鑰匙／她把鑰匙放到吧台上。）

我：「德叔，鑰匙我帶來了。」

我：「我想再確認一次，真的沒有找錯人嗎？」

我：「我不會泡咖啡，也沒有開過店。」

德叔：「突然要讓妳當老闆，想必壓力很大吧。」

德叔：「造成妳的困擾，我很抱歉阿。」

德叔：「不過這件事情是肯定的，就是妳要來繼承這家咖啡館。」

我：「那……我有一個想法。」

我：「我想先當實習老闆。」

我：「店裡怎麼顧、咖啡怎麼泡，我先把這兩樣學起來。」

我：「如果做了之後覺得自己不適合，我就不繼承。」

我：「這樣可以嗎？」

（畫面：德叔露出微笑。）

德叔：「我相信妳一定可以的。」

# 三天後

（畫面：三天後，咖啡館。）

我：「德叔……我們這三天有幾位客人？」

（畫面：德叔微笑。）

德叔：「如果包含找龍眼玩的貓客人，我們這三天總共來了三位客人。」

這三天來過的客人，我都記得。

一位是晚上來喝咖啡的阿伯，德叔叫他坤伯。

一位是路過的客人，坐一下就走了。

再來，就是跟著坤伯來的那隻花斑貓。

兩個人，一隻貓。

我：「不行，再這樣下去這家店要倒了。」

可是咖啡我還在學，開店我也不懂。

我會的，好像只有以前當業務助理做的那些事。

那時候東西賣不出去，都是先去問客人要什麼。

……這裡也可以這樣問嗎？

我也不知道有沒有用。

……還是去問問看好了，問一下也不會怎樣。

我：「德叔，我去附近問問看，大家為什麼不來喝咖啡。」

（德叔從門邊拿了一頂斗笠給我。）

【小圖：斗笠】

（互動：背景維持原場景不切換，小圖先疊上來；玩家點一下，才出下面的句子。講完小圖收掉。）

德叔：「好阿。太陽很大，這頂妳戴著。」

## 市調

（畫面：村子的路上。她拿著筆記本，一戶一戶敲門。）

問了幾戶，筆記本上還寫不到幾行。

（畫面：花斑貓從圍牆上跳下來，看了她一眼，往前走。）

我：「咦，妳不是來店裡的那隻嗎？」

（互動：玩家點花斑貓／貓往前走，她跟在後面。）

貓走進一戶人家的院子，院子旁邊種了好幾棵龍眼樹。

坤伯蹲在院子裡，面前放著一個水桶。

我：「坤伯？原來這裡是坤伯家。」

坤伯：「喔，咖啡店的小姐捏。」

我：「坤伯在忙什麼？」

坤伯：「在弄肥料啦，等一下要拿去澆龍眼樹。」

水桶旁邊有一個空罐子，還有一罐長得很像、還沒開的。

（互動：玩家點地上的空罐子／她拿起來，把標籤轉到正面。）

【小圖：空罐子的標籤】

（互動：背景維持原場景不切換，小圖先疊上來；玩家點一下，才出下面的句子。講完小圖收掉。）

我：「坤伯，這上面寫的是農藥。」

坤伯：「蛤？」

（畫面：坤伯把罐子拿過去，拿得很遠，瞇著眼睛看。）

我：「旁邊這罐才是肥料，還沒開。」

坤伯：「……我老花眼鏡放在屋裡啦。」

坤伯：「兩罐長得一模一樣，誰分得出來。」

坤伯：「這桶我本來就還沒有要用啊。」

他一邊講，一邊把那桶水提到牆角，離龍眼樹遠遠的。

## 坤伯來答謝

（畫面：傍晚，咖啡館。坤伯推門進來，手上提著一個袋子。）

坤伯：「這個給妳們啦，我自己焙的龍眼乾。」

坤伯：「早上那個齁……不要跟別人講捏。」

我：「好，我不會講。」

坤伯：「啊不要站著，來，吃看看啦。」

（坤伯把袋子打開，放在桌子中間。）

袋子一打開，就有一股甜甜的、烤過的香味。

坤伯拿起一顆，拇指一壓，殼「喀」一聲就裂開了。

坤伯：「來，這顆給妳。」

【小圖：龍眼乾】

（互動：背景維持原場景不切換，小圖先疊上來；玩家點一下，才出下面的句子。講完小圖收掉。）

殼還有一點溫溫的。果肉黑黑亮亮，有點黏手。

咬下去軟軟的，很甜，甜完嘴巴裡還留著一點煙燻的香味。

我：「……好好吃喔。」

我：「跟外面買的不一樣，有一個烤過的香味。」

坤伯：「晚上還要顧火烘龍眼乾，怕睡著，才都來這裡喝咖啡。」

坤伯：「人老了，眼睛不行，記性也不行啊。」

坤伯：「德叔，你也吃啦，站在那邊幹嘛。」

（德叔拿了一顆，剝開，放進嘴裡，沒有講話。）

（德叔又拿了一顆。）

坤伯：「啊是有好吃還是沒好吃？」

德叔：「……有啦。」

花斑貓跳上椅子，用手去撥袋子裡的龍眼乾。

一顆龍眼乾滾到桌上，牠自己嚇了一跳。

坤伯：「欸，這個不是給你吃的啦。」

外面天色慢慢暗下來。店裡很安靜，只有剝殼的聲音。

我又剝了一顆。

……這個味道，不知道跟咖啡搭不搭。

德叔：「好阿，比例我來試試看。」

我：「坤伯，下次來，這杯免費招待。」

坤伯：「免費的喔？那我一定來捏。」

## 研發咖啡

很苦，後面還有一個怪味，我吞不太下去。
