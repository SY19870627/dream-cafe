## 這些照片是什麼

- 老闆請德叔端一杯給熟客，**端對了**（找到他那一段想喝的那杯），畫面就慢慢淡成一張照片，停幾秒、再淡回店裡，照片收進記事本的「相簿」。
- 照片是**「回憶畫面」**（Q76）：不是誰用相機拍的，是那一刻、或那一段故事裡某個畫面「如果有人記得的樣子」。所以不用有相機的視角感（不用閃光燈、不用擺拍、人物通常不看鏡頭），可以有一點柔焦、暖光、時間的感覺，但**還是和遊戲同一套手繪畫風**。
- 每位熟客三段：第一、二段是他平常那杯與故事裡的一杯，**第三段是他「最愛的那杯」**。

## 共通規格

- **一張照片一張圖**（D192）：淡入、極慢的推近（約放大 7%）、一道慢慢掃過的暖光都由程式做，**不要畫連續的格子、不要分圖層**。
- 檔名：`photo_<人>_<段>.webp`（人：`yuan` 予安、`zhe` 阿哲、`kevin` 凱文；段：1、2、3），放 `assets/art/`。
- **橫式 4:3、1024 × 768 像素原生、不透明 webp**（承峰 11/4：「改回 1024×768 原生」，D201）：直接用 1024×768 畫出來的原圖，**不要放大、不要銳化**，不要透明背景，不要壓得太狠。手機上大圖約 350 CSS 像素寬，兩倍螢幕剛好；三倍螢幕（約 1050 實際像素，再加推近 7%）會放大約 1.1 倍、稍微軟一點，可以接受。
- **照片裡不放任何文字**（承峰 11/4：「圖上不寫字，改由角色台詞說出來」，D202）：不畫讀得出來的字，也不畫假字行、看不清的字行、螢幕上的字、黑板上的字、信上的字、標籤或招牌上的字；**也不要事後疊字**（不要後製手寫字、不要用字型疊上去）。原本要寫在照片裡的那一句（予安第三張的「煙是甜的」、阿哲第三張黑板上的「阿哲的豆」），改成照片淡入時由那位熟客說出來，程式做。紙、信、黑板、螢幕照樣畫，只是上面沒有字（寫法見下面每一張）。
- **畫面四邊各留約 4% 不放重要的東西**（臉、杯子、手）：程式會推近約 7%，照片的白邊也會蓋掉一點點。
- **圖裡不要畫相框、白邊、膠帶、陰影**：照片外面的白邊、微微的傾斜與陰影由程式畫。
- **不要自己縮圖或裁切**：相簿裡的小縮圖是程式在執行時縮的。
- 畫風：和店裡同一套手繪（平塗加描線、暖光、3/4 角度）。人物用**現有的同一個人**（照 `char_yuan_*`、`char_zhe_*`、`char_kevin_*`、`char_grandpa_*`、`char_deshu_*` 的臉、髮型、衣服；德叔的老錶戴在左手）。店裡的東西照現有的手繪（`assets/art/` 的窗景、桌椅、吧台、黑板層架 `backbar`、杯子 `prop_cup_daily`）。
- **老闆不入鏡**：玩家沒有外型設定，需要老闆時只畫到手或杯子，不畫臉。
- 每張只要一個時段（照下面寫的白天或傍晚），**不用畫白天、夜裡兩個版本**。
- 程式會在照片上加一點點暖色（約 12% 的 sepia）；請照正常的顏色畫，不用自己做舊。

## 和現有美術一致的注意事項

- 人物的臉、髮型、衣服照現有的人物圖畫，**同一個人看起來要一樣**（尤其是予安的長髮與毛衣、阿哲的外套與泥鞋、凱文的眼神、德叔的背心與左手的錶）。
- 店裡的東西（窗景、桌椅、吧台、黑板層架、杯子、龍眼乾袋）照現有的手繪，不要換成另一種款式；店裡的牆是石灰牆加紅磚腰牆、木地板。
- **照片裡不寫字**（D202）：黑板只畫粉筆擦過的痕跡或線條，紙與信是空白或折起來，筆電螢幕只畫亮光或畫面（例如視訊裡的人像），龍眼乾的牛皮紙袋只畫紅色封條、不寫字。
- 不要出現品牌、商標、真實店名。
- 龍眼（橘貓）照 `cat_longan_*`。
- 照片不會出現在 3D 店裡，只在全畫面淡入與相簿裡顯示，所以不用配合店裡的透視。

## 程式怎麼接（給工程，畫師不用看）

- `src/favorites.js` 的 `PHOTOS`：每段一張，`file` 是檔名（不含 `.webp`）。
- `src/art.js` 的 `photoUrl(file)`：第一次要顯示時才下載 `assets/art/<file>.webp`（不在開店時一起載）；下載不到（404）或解不開就用 `photoPlaceholder()` 畫的佔位圖。
- 照片淡入時熟客說的那一句（D202）：`STAGES` 的 `said`（予安第三段「煙是甜的。」、阿哲第三段），顯示在照片下方、和泡泡同一個樣子、標名字；相簿裡點縮圖看大圖時也一樣。沒有 `said` 的照片不顯示。
- 所以：把檔案放進 `assets/art/` 就自動換上，重新整理即可。尺寸不是 4:3 時，畫面用 `object-fit: cover` 從中間裁（會少一點邊），請照 4:3 交。
