# 分鏡格素材說明（assets/art-v56/S/）

取代遊戲裡原本用程式演的動作（點 CSS 信封抽信、點錢包數錢、點抽屜、點存摺放進提款機與 CSS 存摺、CSS 紙袋疊字），改成漫畫分鏡格。
提案：2026-11-24（台北時間）；八組定版：2026-11-25（台北時間），由作者逐張拍板。

- **產圖**：咖啡館畫師（dream-cafe 專屬的 AI 繪圖助理）。圖是 AI 生成後放大，**不是手繪**。
- **框與紙感**：黑框、白邊、紙感都是程式後製加上的，不是手繪框。對外說明時不要寫成手繪。
- **字**：圖上的字都畫進圖（存摺上的 10,000／160,000 是程式以點陣字疊進圖再存檔；紙袋上「提神醒腦」「過目不忘」用霞鶩文楷字型加隨機變化），遊戲程式不另外疊字。
- **規格**：橫式 4:3，每格 2048×1536，RGBA webp。直排多格是同一張圖，格距 64px 透明（2 格 2048×3136、3 格 2048×4736）。
- 不畫人的手（貓爪可以）。
