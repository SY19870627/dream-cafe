## 美術替代與限制

### 沒有原圖的特寫（`manifest.js` 的 status: 'none'）

- **phone：** CSS 畫的中性手機外形，螢幕只有亮或暗，不畫訊息；訊息字放在閱讀框，名牌是「宜蓁」。
- **quilt、basin：** 雨房背景局部放大。
- **cloth：** 在山屋時，把背景的布旗堆局部放大；**在店內（d3-s1、d3-s5 的綁帶）沒有圖，畫面不變。**
- **thermos：** 山屋背景局部放大，但放大的是**爐上的水壺，不是熱水瓶**。

### 美術與劇本對不上的地方

- `road`（d2-s4）沿用 `scene_county_road`。那張其實是開場的「縣道上的店門口」，不是山上的碎石路、站牌、候車亭。
- 老太太只有一張「坐小板凳」的遠景圖，所以 stage 寫的「撐傘」（雨房）、「背對山屋看山」（山屋）、「看報」（大廳）都沒演出，只是把同一張圖放在遠處，四處大小相同。山屋那一處被阿桂立繪擋住時幾乎看不到。
- 德叔、阿桂、宜蓁各只有一種表情，沒有差分。宜蓁立繪是否符合角色設定，沒有經過作者確認。
- 杯把朝向（d1-s1-01）沿用現有的 `prop_cup` 圖，無法照 stage 確認方向。
- 店內是固定鏡頭朝吧台，所以 d1-s1、d2-s1 寫的「靠窗座位與吧台同框」沒做到，窗戶不在畫面裡。

## 原開場的不一致（本輪照規定不改原字）

開場（`src/lines/opening.js`、`src/view/opening.js`）仍有「已故委託人」、「溫度基金」、「經營」等與 v3 設定不合的地方。這些字原樣保留，要改需要作者起稿。

## 沒有演出的 stage

stage 的字一律不顯示。下面列的是畫面或聲音上沒做到的部分。有做到的部分在 `direction.js`：風鈴、手機震動、鋁盆滴水、電梯、閘門、自動門、電台轉小一格、立繪換人或退場、手機螢幕亮暗、龍眼的位置，以及阿桂延到 d2-s2-03 才出場。

**第一天**
- d1-s1-03、d2-s1-02、d1-s5-13：本子特寫只露那一行——用的是闔著的本子圖，沒有翻開的頁面。
- d1-s1-11、d2-s1-09、d3-s1-18：風鈴尾音疊上雨聲、風聲或空調聲，以及色溫淡出——只有風鈴，加上換背景時的淡入。
- d1-s2-05、d2-s3-04：可選手勢（拉被子、手靠近爐口）——沒做。照 stage 本來就可以略過，不影響推頁。
- d1-s2-06、d1-s2-09、d1-s3-04、d1-s4-05、d1-s3（場）：電視的聲音、廣告音樂、電視裡那一聲喊、片尾曲——都沒有音效。
- d1-s4 開頭雨變大、d1-s4-05 回到原本大小、d1-s4-11 雨聲持續到換場——雨聲音量固定。
- d1-s5-01：門關上時雨聲切斷——換場時直接換成店內環境聲。

**第二天**
- d2-s2（場）：前兩頁用山屋外觀的局部裁切——用的是屋內背景。
- d2-s2-03：阿桂側身、話筒夾在肩上——只有一張正面立繪。
- d2-s2-13：風聲降、爐聲近——進場就是暖爐的環境聲。
- d2-s4（場）：站牌、候車亭、車窗框；d2-s4-03 引擎聲由遠到近——沒做。
- d2-s4-04：皮夾特寫——用識別證特寫代替。

**第三天**
- d3-s2-03：訪客單特寫（三格）——沒做。
- d3-s2、d3-s5：手機訊息用畫面內的訊息框——訊息放在閱讀框，手機只是中性外形。
- d3-s4（場）：主管的背影從畫面邊緣走過——沒做，只有台詞和名牌。
- d3-s5：電台在播整點新聞——用的是一般店內環境聲。
