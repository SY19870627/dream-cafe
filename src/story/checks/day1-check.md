

## 自我檢查

### 第 3 天回收契約（這一輪只定契約，不寫台詞）

- **兩線相同的事實**：
  - 文件是「右邊第二格抽屜、藍色那本」，電子檔在共用槽的「交接」資料夾。
  - 後輩當天就找到，文件上標籤很多。
  - 劇情是男人沒追到客運，女人沒上車，怡君中間漏看一段。
  - 她最後只回了一個「好」。
- **`location` 線**：第 3 天後輩見面第一句從文件開口（藍色那本或標籤）。後輩不知道她那天在做什麼。
- **`tv` 線**：第 3 天後輩第一句先問電視，接「追到跟我說」那句（方向是「後來追到了嗎」），第二句才回到文件。怡君可以照實答「沒追到，她沒上車」。
- **兩線都不變的**：交接成功、文件被使用、後輩態度友善。
- **未預埋的事**：「別組借去影印」第 1 天沒有埋，留給第 3 天自己交代。

### 欲望、打擾、收束

- **欲望：成立，但動機薄。** 她親口說「想找個地方看電視」，進房後自己開電視。弱點是她「為什麼今天想做這行」只靠看了本子一眼，我沒有補理由，因為補了就變成自我分析。
- **打擾：成立，這是全天最實的一段。** 代價是具體的：她低頭看訊息時漏看「誰喊了名字」，回完訊息又漏掉女人站起來那段。回店後她自己說出「他為什麼跑，我不知道」，打擾留下了痕跡。
- **收束：半成立。** 「接回自己的時間」只靠兩個動作：手機翻面，以及第二次震動時手伸過去又收回。「沒人催」靠一個事實：訊息是二十分鐘前的，後面沒有別的。我認為讀得出來，但力道輕。如果你讀完覺得「就這樣？」，問題在這裡，不在雨房描寫。

### 三個最擔心不想讀的段落

1. **`d1-s2` 雨房進場（9 頁全旁白）。** 沒有人說話，只有物件清點：床、電視、被子、鋁盆。這是提案自己點名「最容易薄」的地方，我沒有解決，只是壓短。若要砍，先砍 `d1-s2-04`（滴水間隔）和 `d1-s2-08`。
2. **`d1-s4-05`、`06` 片尾名單與贊助商。** 這兩頁是「她真的看完了」的證據，但玩家是在讀一段別人看片尾的描述，可能是全天最無聊的兩次點擊。
3. **`d1-s1` 轉場。** 「門外的地是濕的」接「門裡是一個房間，她沒來過」。她幾乎沒有反應，只有「在門口站了一下」。照「不解釋時空」寫的結果，是第一次穿越顯得太平淡，玩家可能以為漏看了什麼。這一點需要你判斷她第一次該不該多一拍反應。

### 20 條檢核

| 條 | 結果 | 說明 |
|---|---|---|
| 1 破折號 | 過 | 無。 |
| 2 三並列 | 存疑 | `d1-s2-03`「一張床，一台電視，床尾……被子」是三樣清點，後面再接鋁盆變四樣。不是排比修辭，但節奏像。 |
| 3 不是而是 | 過 | 無。 |
| 4 金句收尾 | 存疑 | 各場收在動作上。但「下集會講。」有被讀成小機鋒的風險；「下一頁也只有一行。」是鉤子句，偏工。 |
| 5 說完再總結 | 存疑 | `d1-s3-06`「中間那一段，她沒看到」和回店「中間有一段我沒看到」是同一件事講兩次。前者是當下，後者是她告訴德叔，我保留，但確實重複。 |
| 6 情緒只用詞 | 過 | 全文沒有情緒詞，都寫成動作（翻面、手收回、站一下）。 |
| 7 工整 | 存疑 | 旁白句長相近，多是「她做 A，做 B」結構。雨房那段尤其像。 |
| 8 比喻 | 過 | 無比喻。 |
| 9 同口氣 | 存疑 | 這仍是最大風險。德叔是「沒有。」「嗯。」「哦。」「演什麼。」，怡君盡量寫成完整句（「我出去一下。想找個地方看電視。」），但「店裡有電視嗎。」跟「演什麼。」同樣是無問號短問句。後輩用驚嘆號和雙問號拉開，區隔最清楚。 |
| 10 解說背景 | 存疑 | 「我翻了妳桌上，沒看到」是後輩替劇情交代。怡君回的位置句資訊密，但那本來就是交接內容。 |
| 11 講破 | 存疑 | 「訊息是二十分鐘前的。後面沒有別的。」把「沒人催」指得很近。「她都看完了。」也是。 |
| 12 客服問答 | 存疑 | `location` 線「收到！我去翻。不吵妳了。」太順。回店德叔問、她答、他「哦」，也是一問一答。 |
| 13 寒暄 | 過 | 後輩只有一句「不好意思吵妳」就進正題；店內沒有早安。 |
| 14 公文腔 | 過 | 無抽象名詞串。 |
| 15 副詞代細節 | 過 | 「雨聲很近」「標籤好多」各一處，其餘是具體物。 |
| 16 假推進 | 存疑 | 鋁盆出現三次（剛淹過盆底、滴得比較快、還很空），推進很小。它只是計時器，不是事件。 |
| 17 硬塞口語 | 過 | 後輩有「喔」零個、「好好喔」一個；沒有為過關再加。 |
| 18 標註太用力 | 存疑 | 「他說完，把電台的聲音轉小了一格」是動作標註。杯把那句（`d1-s1-01`）把伏筆寫進旁白，可能太顯眼，實作時可改由圖演、刪後半句。 |
| 19 拉高 | 過 | 沒有句子把看電視講成人生。 |
| 20 完整和解 | 過 | 男人沒看到她、漏看的那段沒補、`tv` 線的「追到跟我說」她沒回、下一頁沒給字。 |

### 改前／改後

| 改前 | 改後 | 原因 |
|---|---|---|
| 德叔：「傘在門邊。」（她剛說外面沒下雨） | 刪掉；德叔只回「嗯。」 | 他預知那邊下雨，變成全知導師。 |
| 怡君：「我什麼都沒帶回來。」德叔：「沒關係。」 | 旁白寫濕鞋印，德叔：「門邊有報紙。」 | 原句替作者講破「空手」（11），德叔那句是安慰台詞，不像他。 |
| 德叔：「好。」／結尾怡君回後輩：「好。」 | 德叔改「嗯。」；怡君的「好」收進旁白 | 兩人用同一個字回話（9）。 |
| 「左上角的台標已經不是現在的樣子。」 | 刪掉，只留醬油和傢俱行贊助 | 太早給時空證據，接近解釋。 |
| 「他沒問她要去哪。」 | 刪掉 | 旁白替德叔的體貼做註解（11、18）。 |

另有三處不在 20 條裡，請你定：

- **標題「鞋子濕了」。** 原提案這段叫「空手」，我改成具體物。正文沒有任何一句指出她空手回來，只靠「沒有取得提示、沒人問」來成立，可能太隱。
- **`tv` 線她最後只回「好」。** 後輩明明說了「追到跟我說」，她沒回。這是為了把答案留到第 3 天，但會顯得她冷淡，跟「兩線都不受懲罰」有點擦邊。
- **貓沒有寫名字。** 開場是否已叫出「龍眼」我不確定，所以只寫「貓」。
